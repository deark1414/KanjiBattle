## 開発用の資料

- Architecture/: 実装構造、画面の所有者、保存処理等の技術メモ。ゲーム仕様の別版ではない。
- Testing/: 日付・条件付きの試験結果。過去の成功を現行版の合格証明に流用しない。直近の[公開・不具合確認](Testing/ReleaseAudit20261027.md)、バランスの[進行再確認](Testing/ProgressionRecheck.md)。
- Art/・Audio/: 制作物の採用元、演出、ライセンス、画像プレビュー。制作段階と実装済みの区別はゲーム仕様を優先する。
- qa/: 画面・フォント等の検査手順。

新機能は構想で設計し、実装・検証後にルール/一覧へ移す。同じ内容を説明する「最新版」の仕様書を追加しない。

仕様一覧の確認: `node scripts/docs/check-game-spec.js`。正本の冊数・キャラ名/ID・融合素材・局別データ・ローカルリンクを照合する。
