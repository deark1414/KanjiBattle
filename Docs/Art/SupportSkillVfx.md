状態: レビュー前。ゲーム未接続。既存のVFX・モチーフ・コマ・スキル性能は変更していない。

## 制作物

| スキル | 単画像 | 想定する動き |
|---|---|---|
| 電・連鎖電撃 | `ChainLightning.png` | 敵同士を順につなぎ、短く表示して消す |
| 糸・引き糸 | `PullThread.png`＋`ThreadWrap.png` | 命中時に巻き付き、対象と一緒に動きながら直線部分を縮める |
| 鈴・再響 | `BellEcho.png`＋`BellNote.png` | 波紋を拡大し、独立した音符を2～3個ランダムに外側へ散らして消す |
| 繭・保護 | `ThreadWrap.png`→消去→`CocoonGuard.png` | 共用の巻き付きが消えた後、別画像の白い繭に囲まれた状態が残る |
| 風 | `WindGust.png` | 左から右へ流れる風の筋。動作例は追風、向風は反転して使用可能 |
| 磁石 | `MagnetBody.png`＋`MagneticPull.png` | 参考画像2枚目のように両極それぞれの先端から小さな波紋を最大3つずつ出し、敵を1マス引き寄せる。中央の大きな波紋は使わない |
| 雨 | `RainDrops.png`＋`RainRipple.png` | 既存の水滴が降り、対象の足元で波紋を繰り返す。雲は出さない |
| 鍛冶 | `ForgeHammer.png`＋`ForgeSparks.png` | ハンマーで叩き、接触時に火花、接触後に対象が赤熱してから元の色へ戻る。継続的な炎は出さない |
| 要塞 | `MortarShell.png`＋`MortarImpact.png` | 既存砲弾が放物線を描き、着弾時に土煙・破片が広がる |
| 砂 | `SandBloom.png` | 砂煙から砂のコピーが現れ、煙だけが消える |
| 波 | `WaveCrest.png` | 波頭が前へ進み、敵を1マス押し流す |
| 草 | `GrassSprout.png` | 地面の若芽と共にコマが左右へ分裂。抜いた草や根は出さない |
| 炭 | `CoalEmbers.png` | 被弾後に熾火と火の粉が現れる。大きな炎は出さない |
| 灯 | `LanternFlame.png` | 近くの味方に暖色の炎が揺らぎ、遠距離弾が逸れる |
| 影 | `ShadowMist.png` | 人型でない影煙を挟んで敵と同じコマに変身 |
| 賽子 | `DiceBody.png`＋`DiceSparkles.png` | 転がってから輝き、1・2は回復、3・4は防御、5・6は攻撃の効果例を順番に表示 |

- 保存先: `Assets/Art/Drafts/VFX/SupportSkills/`。素材ごとにPNG1枚、計23枚（既存再利用5枚を含む）。電・糸・砲弾は512×128、風・波は512×256、その他は512×512。128px論理グリッドを補間なしで4倍表示。アニメーションシート分割や連番フレームの切替は不要。
- 賽子本体は既存の`Assets/Resources/UI/PieceMotifs/Ready/Motif_F1011.png`を再利用。プレビューの出目は動作確認用の固定順で、戦闘の乱数ではない。本体の既存面を描き替えず、確定値は見出しに表示する。回復は既存水滴、防御・攻撃は既存波紋の表示時着色を流用する。
- 雨の水滴は`Assets/Resources/VFX/Animated/WaterHeal/frame_03.png`、要塞の砲弾は`Assets/Resources/VFX/Animated/Gun/frame_02.png`を再利用。元ファイルは変更せず、草案用コピーだけを同じ出力規格に整える。新規素材の原画・プロンプトと、再利用素材の元パスはJSONに記録。
- 原画は同ディレクトリの`Source/`。内蔵image_genによる生成元、全プロンプト、生成時の保存先は`SupportSkillVfx.json`。
- 磁石はU字磁石から発する半円波紋へ変更。新原画は`Source/MagneticRipple.png`。旧鉄粉`Source/MagneticPull.png`・旧磁力線`Source/MagneticFieldLines.png`と生成記録は保持。磁石本体は`Assets/Resources/UI/PieceMotifs/Ready/Motif_F1007.png`、ハンマーは`Assets/Resources/VFX/Weapons/HammerMotion.png`を変更せず再利用する。
- 鍛冶の赤熱は表示時の着色で、コマ画像自体は変更しない。プレビューでは0.7秒で叩き、接触後に赤熱、2.4秒で元の色へ戻る。磁石は0.25秒から波紋を発し、0.75秒から引き寄せる。これらはレビュー用秒数でありゲーム性能を定めない。
- `layout.json`に固定寸法・内容範囲・中央ピボット・接続点を記録。電と糸のローカル前方は右。透明余白まで距離に含めず、内容範囲を接続点へ合わせる。鈴・巻き付き・繭は対象の中心基準で、絵の縦横比を保つ。繭は中央を空け、漢字を見せる。
- 波紋は元の音符なし`Source/BellEcho.png`を再利用し、初回の波紋PNGとのバイト一致を確認。独立した音符の原画は`Source/BellNote.png`。音符一体型の前案`Source/BellEchoNotes.png`も制作記録と共に保持。
- 音符1枚を2～3個複製し、発動ごとに位置・大きさ・傾き・開始の遅れを変える。外側へゆっくり移動して消え、漢字の周囲42pxを空ける。プレビューの装飾専用シードを用い、毎フレームや方向変更で散り方を引き直さない。一時停止時の再描画は同じ絵を維持し、再生ループまたは最初から再生で別の散り方になる。ゲーム側の乱数・技能確率は変更しない。
- 繭のレビュー再生は巻き付き、短い消去区間、保護状態、ループ用フェードで構成。演出の重なりはなく、巻き付きだけが残る表現ではない。プレビューの秒数は実ゲームの効果持続ターンを定めるものではない。
- HTML上の動きは独立したレビュー用シミュレーション。ダメージ、乱数、スキル確率、実際の引き寄せ成否は解決していない。プレビューの成功をUnityへの接続確認と読み替えない。

