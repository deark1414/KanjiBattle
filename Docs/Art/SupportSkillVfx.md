状態: レビュー前。ゲーム未接続。既存のVFX・モチーフ・コマ・スキル性能は変更していない。

## 制作物

| スキル | 単画像 | 想定する動き |
|---|---|---|
| 電・連鎖電撃 | `ChainLightning.png` | 敵同士を順につなぎ、短く表示して消す |
| 糸・引き糸 | `PullThread.png`＋`ThreadWrap.png` | 命中時に巻き付き、対象と一緒に動きながら直線部分を縮める |
| 鈴・再響 | `BellEcho.png` | 音符付きの波紋を味方の位置で拡大・消去する |
| 繭・保護 | `ThreadWrap.png`→消去→`CocoonGuard.png` | 共用の巻き付きが消えた後、別画像の白い繭に囲まれた状態が残る |

- 保存先: `Assets/Art/Drafts/VFX/SupportSkills/`。状態ごとにPNG1枚、計5枚。方向性のある2枚は512×128、鈴・巻き付き・繭の保護は512×512。128px論理グリッドを補間なしで4倍表示。アニメーションシート分割や連番フレームの切替は不要。
- 原画は同ディレクトリの`Source/`。内蔵image_genによる生成元、全プロンプト、生成時の保存先は`SupportSkillVfx.json`。
- `layout.json`に固定寸法・内容範囲・中央ピボット・接続点を記録。電と糸のローカル前方は右。透明余白まで距離に含めず、内容範囲を接続点へ合わせる。鈴・巻き付き・繭は対象の中心基準で、絵の縦横比を保つ。繭は中央を空け、漢字を見せる。
- 鈴の旧原画は`Source/BellEcho.png`に維持。音符追加後の原画は`Source/BellEchoNotes.png`。制作記録にも前案を保持。
- 繭のレビュー再生は巻き付き、短い消去区間、保護状態、ループ用フェードで構成。演出の重なりはなく、巻き付きだけが残る表現ではない。プレビューの秒数は実ゲームの効果持続ターンを定めるものではない。
- HTML上の動きは独立したレビュー用シミュレーション。ダメージ、乱数、スキル確率、実際の引き寄せ成否は解決していない。プレビューの成功をUnityへの接続確認と読み替えない。

## 再生成と検査

```bash
node scripts/art/build-support-skill-vfx.js
KANJI_ART_PORT=8799 node scripts/art/serve-gallery.js
node scripts/art/check-support-skill-vfx.js
```

画像検査: 5枚のRGBA透過、非空、四辺の余白、固定寸法、4pxブロック整合、鈴・繭中央の実質透明な空間（アルファ最大1/255）を確認する。

画面検査: 4種類のスキルの4方向での動作変化、PC1280px・スマホ390pxの非空描画、はみ出しなし、波紋の縦横比、再生関連の操作を確認する。繭は420時点で巻き付きと保護が同時表示されないこと、保護状態が後の時点でも維持されることを確認する。記録は`tmp/skill-vfx/report.json`、画面画像も同ディレクトリ。

Unity・戦闘ルール・WebGLの再ビルド／回帰は未実施。レビュー後に承認素材のみを本番へ移し、成功したスキルのタイミング・実際の対象・移動と結び付けて検証する。
