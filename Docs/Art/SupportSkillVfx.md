# 電・糸・鈴のスキル画像草案

状態: レビュー前。ゲーム未接続。既存のVFX・モチーフ・コマ・スキル性能は変更していない。

## 制作物

| スキル | 単画像 | 想定する動き |
|---|---|---|
| 電・連鎖電撃 | `ChainLightning.png` | 敵同士を順につなぎ、短く表示して消す |
| 糸・引き糸 | `PullThread.png` | 使用者と対象をつなぎ、対象の移動に合わせて縮める |
| 鈴・再響 | `BellEcho.png` | 再発動する味方の位置で拡大・消去する |

- 保存先: `Assets/Art/Drafts/VFX/SupportSkills/`。各効果はPNG1枚。方向性のある2枚は512×128、鈴は512×512。128px論理グリッドを補間なしで4倍表示。シート分割やフレーム切替は不要。
- 原画は同ディレクトリの`Source/`。内蔵image_genによる生成元、全プロンプト、生成時の保存先は`SupportSkillVfx.json`。
- `layout.json`に固定寸法・内容範囲・中央ピボット・接続点を記録。電と糸のローカル前方は右。透明余白まで距離に含めず、内容範囲を接続点へ合わせる。鈴は回転中立・中心基準。
- HTML上の動きは独立したレビュー用シミュレーション。ダメージ、乱数、スキル確率、実際の引き寄せ成否は解決していない。プレビューの成功をUnityへの接続確認と読み替えない。
