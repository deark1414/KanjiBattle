# 追加スキル演出の進捗

集計日: 2026-10-25。追加・変更キャラの25系統を対象とする。画像の枚数ではなく、スキルごとの動作例を1件として数える。通常キャラの既存演出、将来の進化・超融合・究極融合の専用演出は別枠。

## 集計対象

- 通常キャラの追加・変更8系統: 甲、鈴、糸、影、丑、電、風、鉄。
- 実装済み通常融合17系統: `BattleFusionRules.Recipes`の全17件。
- 草案済みは画像と独立HTML動作例の完成を意味する。本番接続・承認済みという意味ではない。
