# キャラクターのコマ・モチーフ制作

対象: 通常26系列、通常融合17種、敵専用の竜、砂の分身。未実装の進化・超融合・究極融合は対象外。

初回制作・実装コミット: `54f285e`。以下の表現方針はユーザーレビュー後のドット絵改訂版。

現行方針（2026-10-25）: 比較表で以前のモチーフがある20組は元画像を再利用する。コマ90枚は変更しない。以前のモチーフがない25組のみ新規制作画像を使用する。甲・弓・酉にも、比較表の旧画像（鎧・矢・鳥）を適用する。これは以前の画像を使う指示によるもので、現キャラの題材に合わせた再制作は行わない。

## 表現方針

- コマは既存の五角形と筆文字を継承。味方は木地と墨、敵は朱塗りと白文字で識別する。融合は二重の縁を加える。
- 漢字の形と意味が主役。一文字は大きく、二文字は縦組み。HP・向き・レベル表示の場所を確保する。
- モチーフは和風の透過ドット絵。通常はコマ、召喚時は大きく出現して消え、軍勢・編成では選択時のみ表示する。
- 既存モチーフ20組は`reviewed-motif-crops.json`に記録した画像・UV範囲・縦横比・回転を維持する。現行の表示倍率1.18は維持し、コマと表示タイミングを変えない。残る25組は新規ドット絵を使い、砂の分身は本体と同じ砂の絵を使う。
- 新規生成は内蔵image_genを使用。原画を保存し、透過の内容領域を64pxの論理グリッドへ収め、補間なしで512pxへ拡大する。原画は上書きしない。コマは128pxで描画し、補間なしで256pxへ拡大する。
- 砂は砂山・砂粒のキャラクター。人型やゴーレムにせず、分身も表示名は「砂」とする。「砂偶」は使用しない。スキル名は「砂の分身」で、分身の性能・生成条件は変更しない。
- コマの文字は画像生成に任せず、Yuji Boku書体で正確に描画する。ライセンスを同梱する。今回のモチーフ復元では現行コマを据え置くため、以前のコマと同じ書体・意匠へ戻す変更は含まない。

## 再生成・確認

1. `node scripts/art/build-character-art.js`でカタログと新規分を再生成する。旧画像20組を優先して参照し、その20組の画像とコマを再描画しない。必要な素材はプロジェクト内にあり、画像APIは不要。
2. Unityの`KanjiBattle.Editor.CharacterArtImporter.ImportProduction`で取込・参照を確認する。
3. `node scripts/art/check-character-art.js`で135画像の読込と、旧20組の参照・UV等の一致、新25モチーフ・コマのドットグリッドと、一覧の全読込・分類・拡大・スマホ表示を確認する。旧画像に新規画像用の寸法や64pxグリッドを強制しない。
4. `node scripts/art/serve-gallery.js`で一覧を開く。

ゲーム内確認はE2Eの`art-standard`、`art-dice`、`art-sand-mobile`、`art-selection`。一覧と編成枠の同じキャラは同時に召喚されることがあるため、表示数を1に限定せず、選択したキャラ以外のモチーフが出ていないことを確認する。召喚後は元の漢字コマへ戻る。

繭の保護表示は漢字へ文字を重ねない金色の枠へ変更。敵用コマは朱塗り・白文字で、通常コマと融合コマの両方を用意した。
