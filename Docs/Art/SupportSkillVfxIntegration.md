# スキル演出のゲーム接続

更新日: 2026-10-25。対象25系統の素材をゲームコードへ接続。公開版のデプロイではなく、ローカルWebGLの確認用ビルド。

## 変更

- 甲羅は既存の緑の甲羅を64px相当の粗いドットへ簡素化。元モチーフは保持。
- `Assets/Resources/VFX/SupportSkills/`へ36素材を配置。PNGはPoint・Clamp・RGBA32・圧縮なし。JSONに表示範囲を保存し、透明余白を除いてサイズを合わせる。
- 共通描画は`BattleManager.SupportSkillVfx.cs`。位置・回転・拡大・透過を使用し、炭の状態画像と賽子の出目だけは承認どおり画像を切り替える。
- 戦闘速度・一時停止へ追従する。装飾乱数には`System.Random`を用い、戦闘の`UnityEngine.Random`を消費しない。
- 防御画像は対象の子、攻撃画像は武器オーバーレイへ配置。移動追従・死亡・結果・画面終了時の清掃を行う。

## 発動への接続

| 系統 | 実際の接続先 |
|---|---|
| 電 | 連鎖で実際に選ばれた敵同士を順につなぐ |
| 糸・影 | 命中時の糸と巻き付き、変身成功後の影煙 |
| 鈴・風鈴 | 再発動成功時に対象キャラへ波紋と音符 |
| 甲 | 実際に肩代わりが発生した本人と守られた味方に粗い甲羅 |
| 丑 | 既存の勝利リザルトの経験値倍率表示を維持。独立HTMLのカウント演出は表示案であり、実ゲームのリザルトへ新たな牛画像は追加していない |
| 風・鉄 | 移動バフ／デバフの発生と、選択された形態の変化 |
| 双剣・散弾 | 既存の範囲計算で選んだ対象への武器／弾。双剣は2回の剣動作 |
| 戦士・衛兵 | 既存剣／槍／盾に加え、実際の攻撃強化と回復時の表示 |
| 鍛冶 | 強化対象の武器キャラへハンマー→火花→赤熱 |
| 波・磁石 | 押し流し対象への波、移動成功時に両極からの波紋 |
| 山・炭 | ダメージ返還時の石片と返還弾、実際の燃焼状態の切替 |
| 要塞・賽子 | 砲撃対象へ放物線と着弾、解決済みの出目を必ず最後に表示 |
| 雨・砂・草・繭 | 回復対象・範囲マーカー、生成成功したコピー、実際の保護フラグ |
| 灯 | 遠距離回避が成立した味方へ炎の揺らぎ |

性能・確率・対象の選び方は変更しない。HTMLは方向・素材を比較する独立見本なので、実戦の演出密度・秒数・同時表示数が完全一致するものではない。

## 検査

- 素材36件の取り込み・寸法・フォーマット検証。
- Unityの`BattleRuleRegression`と`GameDataValidator`。
- HTML見本の25系統・4方向・PC／スマホ・透過余白・出目整合。
- WebGL用の独立テスト7件: 賽子6確定、炭の消火／燃焼、繭付与／消失、甲羅、鍛冶、磁石、電撃。実テクスチャ名・寿命・一括清掃を検査し、各発動時に戦闘乱数が不変であることも確認する。
- この独立テストは布陣中の描画専用プローブ。実戦ルールは別の既存シナリオと回帰検査で確認する。

最終結果: Unityの素材36件の取り込み・ルール回帰・データ検査・ローカルWebGLビルドが成功。Playwrightは描画専用7件＋実能力・境界条件17件の計24件すべて成功。テストハーネスの単体検査9件、HTML見本の画像・表示検査も成功。結果と画面は`tmp/e2e/support-vfx-final/`、Unityログは`/tmp/kanji-support-vfx-build-final.log`。
