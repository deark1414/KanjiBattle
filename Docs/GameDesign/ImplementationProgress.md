# 新仕様の実装進捗

更新日: 2026-10-22

## 第1段階: 初期配置

実装したもの:

- 縦7×横6の盤面。上2段が敵、下2段が味方。
- 敵リストに基づく固定の初期配置。
- 味方を選び、空きセルへ移動、味方同士を入れ替える布陣画面。
- 開戦前の配置保存、次の出陣での復元。同じ漢字を複数使う場合も個別識別。
- 自動連戦は確定済み布陣を使い、配置操作待ちにしない。
- 中央領域で毎戦生成する水、開戦時にも発動し得る非公開の罠。
- 縦横切替時に盤面とコマの両方を再計算するレイアウト。

この段階では既存の育成・加入・施設の保存形式を変更しない。新名簿への置換とセーブ移行はまだ実施していない。

## 第2段階: 行動AIの共通化

実装したもの:

- 剣・槍・矢・銃・投石・火球・水回復は、有効な対象がいれば確率不発にならない通常役割として使用。
- 矢・銃は味方越しに射撃、槍は味方で遮蔽。水は射線を遮らない。
- 射撃可能なら接近せず、射撃できない位置からは攻撃可能な位置へ移動。
- 水は自分と隣接味方のうちHP割合が最も低い負傷者を回復。
- 斜め1マスの距離、同距離のランダム選択、動物の味方通過と停止禁止を共通化。
- 対象選択・射線・移動先探索を戦闘管理から分離。

Unityの戦闘ルール・データ検証と、ブラウザの配置・開戦・保存復元・縦横表示の9項目が成功。全ステージの勝率・周回時間、新しい全キャラの能力まで確認したものではない。

コミット: `f802b0d` 配置基盤、`ab4ed2c` 配置接続と確認用プレビュー、`315e8e6` 行動AI。以前からの演出・速度・育成関連の未コミット変更は混ぜていない。

## これから

1. 行動AIの基本実装を土台に、通常融合の素材選択へ進む。新キャラ固有の標的選択や行動は個別実装時に追加する。
2. 通常融合の素材選択・起点・初回非公開・戦闘後復元を実装し、少数のレシピで通し確認。
3. 新名簿と能力を順に実装し、周回・敵編成・施設と合わせて調整。
4. 進化・試練・超融合・究極融合は通常融合の基盤確認後。

初期配置だけで新仕様全体が完成したとは扱わない。盤面・距離の変更により難易度も変わるため、既存の勝率を合格根拠として流用しない。

## キャラクターアイコン

動作検証は既存の漢字コマと名前表示で進める。全キャラ分の新しい絵の完成を待たない。

並行して固める対象は、通常／進化／融合の見分け方、2文字・長い固有名の表示、選択中のモチーフ演出。個別のモチーフ絵は能力・採用内容の安定したものから制作する。忍など看板キャラは優先候補だが、今回は新規イラストを生成していない。

## 確認手段

- Unityの `BattleRuleRegression` と `GameDataValidator`。
- `scripts/visual/check-deployment.js`: 実ブラウザで配置待機・入力・移動・敵陣拒否・開戦・復元を確認し、縦横の画面写真を保存する。
- 確認用ビルドは既存の公開用プレビューと分離した `tmp/deployment-preview/game`。外部公開・デプロイはしていない。

詳細な実装境界は [初期配置の実装](../Architecture/BattleDeployment.md) を参照。
