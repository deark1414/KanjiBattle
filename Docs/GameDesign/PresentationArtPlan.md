# KanjiBattle 表現強化アート計画

更新日: 2026-09-29

## 目的

漢字を読めないプレイヤーにも駒の役割を即座に伝えつつ、一覧、行軍、戦闘を同じ視覚言語でつなぐ。
駒本体の可読性を最優先にし、意味を補うモチーフは常時表示しない。待機、編成一覧、戦闘開始、技能発動など、注目が集まる短い瞬間だけ駒から現れる演出にする。

## 共通アートルール

- 表現: 和風戦術ゲームに合う、意図的に解像度を抑えたドット絵調。高精細な生成画像をそのまま使わない。
- 出力: 透明背景 PNG、正方形 256 x 256 px を基本単位とする。駒から飛び出す向きは上方向を正面とし、実行時に回転する。
- 密度: 太い輪郭、少ない色数、明快なシルエットを優先する。細かい写実的な木目、強い発光、写真風の陰影は使わない。
- 色: 味方・敵の所属色は駒本体と UI が担う。モチーフは種類固有色を保ち、敵用の別絵を作らない。
- 余白: キャンバス外周の 12% を安全域にする。駒の文字、HP バー、盤面セルを隠さない。
- 導入: 素材が全セット揃い、一覧のコンタクトシートで大きさ、彩度、輪郭を確認するまでゲーム画面へ接続しない。

新規に作る待機アイコンは 15 点だけに絞る。既存の技能 VFX を複製・再生成せず、発動時には現在の素材をそのまま使う。

紋章と太鼓はキャラクター、施設、戦闘ルールのいずれにも対応していない。最初のコンタクトシートに紛れた試作用の余計な候補なので、本制作では作成も使用もしない。

## 駒と盤面の外装セット

### 駒

- 駒の輪郭: 現行の読みやすい木札形状を維持し、外周に彫りの浅い木縁と小さな金具を追加する。
- 所属: 味方は青、敵は赤を盤面上で明快に保つ。選択、回復、被弾、罠は現行の意味色を優先する。
- 等級: 追加の常設バッジを増やさず、レベルと HP バーを邪魔しない。
- 画像位置: 漢字と HP バーの安全域を固定する。モチーフは駒の外側へ短時間だけ出す。

### 盤面

- 地形: 序盤は土、自然章は土と草、城・関所は石畳と割れた石畳を基調とする。
- 水: 土地の上に無理に重ねず、用水路・小川として専用の水面と岸を使う。
- マス: 地形の連結を保ち、効果マスだけに控えめな縁取りを重ねる。通常マスの線を強くしすぎない。
- フレーム: 木枠、金具、方位といった共通部品を一式として作り、戦闘・稽古・ステージ情報に再利用する。

## 画面別の使い方

| 画面 | 常時 | 短い演出 |
| --- | --- | --- |
| 軍勢一覧 | 駒と状態のみ | 数秒ごとにランダムな所持駒からモチーフが一度現れる |
| 編成 | 駒と性能のみ | 選択した駒から一度だけモチーフが現れる |
| 行軍 | 敵駒とステージ情報 | 敵駒が一定間隔で小さくモチーフを見せる |
| 戦闘開始 | 駒、HP、地形 | 各陣営が一度だけモチーフを見せる |
| 戦闘待機 | 駒、HP、地形 | 長時間無操作時に低頻度で短く表示する |
| 技能発動 | 駒、技能 VFX | 既存の技能 VFX を主役にし、モチーフは起点の予告に留める |

## 音の制作方針

画像セットの方向性を確定した後、音も同じ「木、鉄、紙、土、水」を共通素材として置き換える。

| 種別 | 必要なセット | 役割 |
| --- | --- | --- |
| BGM | 城下、行軍、通常戦、ボス戦 | ループの継ぎ目がない四曲。音色とテンポを統一する |
| UI SE | 決定、戻る、強化、解放 | 木札と小さな金具を中心に、操作を邪魔しない短音 |
| 戦闘 SE | 通常攻撃、武器、遠隔、自然、防御、動物、竜 | 素材感を共有し、技能ごとの聞き分けを作る |
| 状態 SE | 回復、被弾、勝利、敗北、縁加入 | 結果が一瞬で分かる短い合図 |

現在の `GameAudio` は城下・通常戦・ボス戦の BGM と技能別 SE を読み分けられるため、素材が揃った後は音源の差し替えと音量調整を中心に進める。

## 実施順

1. この規約に沿って、新規 15 モチーフと既存 VFX の参照を一枚のコンタクトシートで確認する。
2. 承認済みの新規画像だけを透過素材として個別に切り出し、既存 VFX と同じ縮尺・余白で検品する。
3. 駒本体と盤面フレームを差し替え、一覧・行軍・戦闘で同じ見た目を確認する。
4. モチーフを共通の表示機構で接続し、画面ごとの発生頻度だけを変える。
5. BGM と SE を一式で差し替え、画面遷移と戦闘中の音量を調整する。
6. 縦長・横長・WebGL を通しで確認し、まとまった一回の更新として公開する。

## 完了条件

- コンタクトシート上で、全素材の大きさ、彩度、輪郭の太さ、余白が揃っている。
- 漢字を読まなくても、武器・防御・遠隔・自然・動物・数字の大分類を見分けられる。
- モチーフが漢字、HP、HP バー、盤面の重要情報を覆わない。
- BGM と SE が出所・利用条件を記録したうえで、同じ音量基準に揃っている。
- 全画面で同じ駒・盤面・モチーフを使い、画面ごとの独自実装を増やさない。
