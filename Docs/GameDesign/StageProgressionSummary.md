# Stage Progression Summary

Last Updated: 2026-08-13

この表はリリース前の仕様固定用メモです。`Assets/Data/stages.json`、`characters.json`、`facilities.json` と、研究所のキャラクター解放順を基準にしています。

- 全8章、40ステージ構成です。
- Stage 3 は序盤の2対1詰まりを避けるため、敵を `三` 単体に固定します。
- 実効編成枠は「ステージ側の `slotCount`」と「訓練場による編成枠」の小さい方です。
- プレイヤー初期レベル上限は5、魔導書庫の強化で段階的に上がります。
- 中位数字の追加ダメージは対象周囲ではなく、自分周囲8マスに発生します。
- 竜は単体ボスとして調整し、増援で圧を出します。

## Number Passive Direction

- 下位数字（一二三）: 自軍の数字種類数に応じた小攻撃バフ。1種類ごとに+3%、最大+9%。
- 中位数字（四五六）: 自軍の数字種類数に応じた微小攻撃バフ。1種類ごとに+2%、最大+6%。通常攻撃時、自分周囲8マスの敵に攻撃力25%の追加ダメージ。
- 上位数字（七八九）: 自軍の数字種類数に応じた中攻撃バフ。1種類ごとに+6%、最大+18%。通常攻撃時35%で、主対象以外の低HP敵へ攻撃力60%の追撃。
