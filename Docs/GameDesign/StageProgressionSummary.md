# Stage Progression Summary

この表はMVP用の8章構成と、研究所によるキャラクター解放条件を同時に確認するためのメモです。

- 6章は属性、7章は動物、8章は上位数字+ラスボスです。
- 最終ステージ名とボス表記は、将来の`龍`と区別するため`竜`を使います。
- 味方編成枠は終盤まで段階的に増え、最終章で6枠になります。敵の初期配置枠も最大6です。
- 訓練場の上限解放はStage 5/12/25/35で、実効編成枠がステージ表の3/4/5/6枠進行に追いつく想定です。
- 通常ステージでは、数的不利とレベル不利を同時に強くしすぎないように調整しています。
- 必須系施設（研究所/訓練場/魔導書庫/城門）のSP負担は軽めにし、召喚加護や便利施設へ回す余白を残します。
- AllyLvCapは、魔導書庫を可能な範囲で解放・強化した場合の挑戦時レベル上限目安です。

## Number Passive Direction

- 下位数字（一二三）: 自軍の数字種類数に応じた小攻撃バフ。最大+9%。
- 中位数字（四五六）: 自軍の数字種類数に応じた微小攻撃バフ（最大+6%）+ 通常攻撃時に対象周囲へ25%小ダメージ。
- 上位数字（七八九）: 自軍の数字種類数に応じた中攻撃バフ（最大+18%）+ 通常攻撃時35%で低HP敵へ60%追撃。
