# Stage Progression Summary

全8章40ステージで構成する。ステージの敵編成、報酬SP、出撃枠、増援条件は `Assets/Data/stages.json` を唯一の正とする。

## 進行

1. ステージを勝利してSPと出撃仲間の経験値を得る。
2. 初回の敵撃破で仲間候補を記録する。
3. 勝利を重ねて候補との縁を進め、確定値に達すると加入する。
4. SPで施設を解放・強化し、編成枠、経験値効率、戦闘速度、再戦、SP効率を整える。
5. 各章の5ステージ目をクリアすると次章が自動解放される。

## 章構成

| 章 | ステージ | テーマ |
|---|---|---|
| 1 | 1-5 | 下位数字 |
| 2 | 6-10 | 武器 |
| 3 | 11-15 | 防御 |
| 4 | 16-20 | 中位数字 |
| 5 | 21-25 | 遠距離 |
| 6 | 26-30 | 属性 |
| 7 | 31-35 | 動物 |
| 8 | 36-40 | 上位数字と竜 |

ゴールド、ガチャ、召喚確率、研究対象の手動選択は使わない。
