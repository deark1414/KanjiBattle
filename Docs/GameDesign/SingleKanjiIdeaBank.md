# KanjiBattle 一文字キャラクター候補帳

作成日: 2026-10-20 / 状態: 発想用の候補集。追加キャラ・進化・融合の採用表ではない。

## 1. 目的と扱い

漢字一文字から、姿・役割・背景・進化・融合の発見を広げるための候補帳。現在のキャラを増やす決定ではなく、一巡したレシピ選定とは分けて保管する。

- 基本キャラ・進化は一文字を軸にする。融合は2文字、超融合の神話的な固有名は長い名前も候補に残している。
- 追加キャラには全員の進化を必須にしない。進化相当の単独キャラとして出す選択肢もあるが、各字の区分や取得方法をここで確定しない。
- 具体物だけでなく、姿や素材との関係を納得できる概念も候補にできる。ただし意味の広さだけで万能キャラにしない。
- 動作主体の名前は当面避ける方針を維持する。候補帳に書いたことを例外の採用とは扱わない。
- 字の印象やゲーム上の発想は創作。字源・語源・神話の正確な説明ではない。採用前に辞書・文化資料・読み・字体・フォント表示を確認する。
- 既存キャラ、進化先、融合先の字も見えるように載せるが、同じ字で別キャラを重複実装する提案ではない。

## 4. 次に掘り下げやすそうな字

優先度は提案。全てを初期実装する意味ではない。

| まとまり | 先に比較する字 | 理由 |
|---|---|---|
| 新しい姿を作りやすい | 月・鬼・鴉・鏡・鎖 | 一字から対象の見た目を想像しやすい。既存の火水木土と違う姿を試せる |
| 自然の幅を広げる | 氷・雪・海・渦 | 天候・大きな水・回転などの違いがある。ただし新状態異常や物理表現は別途評価 |
| 漢字の雰囲気が魅力 | 暁・朧・冥・妖 | 見た目と能力の関係が決まれば強い。名前の雰囲気だけでは採用しない |
| 既存案の見せ方の比較 | 嶺・焔・狼・獅・鷹・龍 | 山・炎・大口真神・虎・鳥・竜などと見比べ、増設が必要か判断できる |

日・月・光・闇のような対になる字は魅力があるが、対を揃えるためだけの大量実装をしない。新キャラの数を先に決めず、単体の楽しさと既存キャラとの差を見て選ぶ。

## 5. 採用へ進める時の確認枠

| 確認点 | 書く内容 |
|---|---|
| 字と意味 | 一文字、読み、採用する意味、参考資料 |
| 姿 | 一字だけでも想像できるか、具体的なモチーフを描けるか |
| 単体の役割 | 融合部品でなくても採用する理由があるか |
| 既存との差 | 名前・見た目・能力が重複する相手と違い |
| 出し方 | 通常キャラ、進化、融合、超融合、進化相当の単独キャラ、敵専用等 |
| 進化・融合 | 自然なつながりがある場合だけ記入。無理に全欄を埋めない |
| 必要な新ルール | 分裂・命中・召喚・瞬間移動・新地形など、既存の基盤にないもの |
| 字の表示 | 使用フォント、つぶれ、似た字、端末での可読性 |

レシピに使う段階では、進化形の素材代用禁止、動物の進化前融合不可、融合結果を再び素材にする連続融合未採用、共通進化枠の規則を守る。候補帳の抽象語や異形を載せたことを、これらのルール変更とは扱わない。

### 牛＋虎→鬼

ユーザー追加の超融合候補。牛は丑の進化形、虎は寅の進化形なので、素材2枠と共通進化枠1つを使う。丑＋寅の通常融合ではない。丑→牛の第4章追加は採用したが、レシピの採用、鬼の能力・数値、牛の具体的な加入局は未決定。

鬼門の丑寅と、鬼の牛の角・虎皮の姿を結び付ける説明がある。[同志社女子大学「鬼」の話](https://www.dwc.doshisha.ac.jp/research/faculty_column/18257)。鬼の全ての姿や成立を一つの説だけで説明するのではなく、この融合の納得感を補う文化的な参照として使う。

一文字でも切り札の姿が明確で、武器・自然物とは違う融合の発見を作れる候補。神話的な名前だけで既存の超融合より強くする前提にはしない。残る十二支を揃えること自体より、単体の役割と組み合わせの楽しさを確かめて採否を決める。
