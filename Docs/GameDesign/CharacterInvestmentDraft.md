# キャラ別ツリー育成

更新日: 2026-10-26
状態: 方針確定・基本実装済み。通常キャラへの投資を融合へ引き継ぎ、強化だけ無料で振り直す。数値は仮調整。

## ねらい

素のHP・攻撃・防御は共通レベルで育て、城下ではスキル効果・発動率を育てる。戦果を仲間加入・増枠・機能解放・スキル強化へ配分する。全枝は最終的に開放可能で、永久に取れない排他選択は作らない。節目でスキルの挙動を抜本的に変える案は、今回は採用しない。

## 採用仕様・初期調整値

- 共通の軍師レベルを維持する。キャラごとの経験値稼ぎは増やさない。
- キャラのノードは1体につき1つ。未加入なら購入で加入し、加入後は同じノードを繰り返し強化する。個別のHP・攻撃・守備ノードは廃止する。
- 通常は効果I（戦果4・第5局）→効果II（戦果8・第20局）。各段階で既存スキルの主効果を基礎値の10%分強化する。確率判定のある槌・木・土・午・酉・寅・壁は、間に発動率+5ポイント（戦果6・第10局）が入る。
- 鈴は発動率+5ポイントを2回。風は追風・向風の持続+1ターンを2回。各キャラの加入章より早くは強化できず、後半キャラは加入時点で複数回強化できる場合がある。確率は上限95%、剣・弓・銃などの確定役割スキルは100%を維持する。
- 攻撃役はスキル威力、水は回復量、数字は結束の攻撃上昇量、盾は軽減率、甲は肩代わり率、壁は反撃割合、土は罠ダメージ、影は変身時に写す攻撃力、丑は経験値の追加ボーナスを伸ばす。射程・移動距離・敵選択AIは変えない。
- 5カテゴリに共通強化を2段階ずつ置く。各段階で対象の既存スキル効果を基礎の5%分強化。Iは戦果10・第10局、IIは戦果18・第25局でIが前提。武具は攻撃技能、守備は軽減・肩代わり・反撃、数・支援は結束・糸・変身・再響、自然は風以外の攻撃・回復・土罠、動物は攻撃技能と育成支援を対象にする。
- 個別とカテゴリの効果増分は加算し、通常キャラで最大+30%。確率はポイント加算。鈴のカテゴリ効果だけは基礎再発動率を倍率強化してからポイント分を足す。甲は肩代わり量も負担も増えるため、無料振り直しで調整可能。
- 融合の素のHP・攻撃・防御に投資倍率は掛けない。素材のスキル効果倍率・確率ポイントの平均を、対応する融合スキルの威力・回復・バフ・反撃・回避・分身性能へ適用する。カテゴリを融合先で再度掛けない。風の持続は通常の風専用で、風鈴は鈴の再発動率を引き継ぐ。磁石の距離と対象数、繭の保護回数など固定ルールは変えず、これらには効果倍率を適用しない。
- 敵はプレイヤー投資を参照しない。砂・草の生成コピーは確定済み能力値を使い二重強化しない。影の変身は写す攻撃力だけ強化し、変身後のスキルに影の倍率を重ねない。HPは従来どおり保持する。
- 再戦・速度・稽古・融合などの機能施設は残し、ステータス／技能の全体倍率施設と区別する。
- 無料の振り直しは確認画面付き。キャラとカテゴリのスキル強化に支払った戦果だけを全額返す。加入・増枠・施設・共通レベル・経験値は保持する。返却時に台帳を消去し、二重返却しない。
- 旧4種の全体強化施設は購入不可・効果無効とし、既存の購入・強化費用は初回起動時に返却する。機能施設と編成枠は維持する。

## 保存と予算

- 保存先は `KanjiBattle.CharacterInvestment.Paid.v1`。ノードIDと支払額を保存する。全進捗削除では消すが、育成振り直しでは他の進行キーを触らない。
- 旧個別ステータス強化（保存IDの末尾0〜3）も起動時に支払額を返却し、新しいスキル強化や他の進行は保持する。保存IDを別用途に流用しない。
- キャラ59段階・カテゴリ10段階のスキル強化で戦果494。加入・全増枠・残存施設の最終強化まで含む総額は1703。表40局の基礎戦果合計496の約3.43周分。戦果倍率なしでも各局5勝以内の総予算に収まる。
- 初回40勝だけで全購入できる設計ではなく、既存方針の少量周回込み。到達順と難易度を踏まえた実戦の所要時間は別途調整する。

## 検証と継続調整

- 表クリアまでの想定周回数・獲得戦果と、全解放の総費用を照合する。全解放が予算上可能なことを確認してから費用を決める。「初回クリアだけで全購入」か「既存の少量周回込み」かも区別する。
- 既存施設に支払った資源と得た効果を、移行時に失わせない。表示だけ先に消したり、全体倍率と個別倍率を両方適用したりしない。
- 同キャラ複数編成、融合、進化、変身、砂のコピーで効果の参照元を揃える。敵にプレイヤーの強化を適用しない。
- ダメージだけでなく回復・軽減・肩代わり・発動率など、能力ごとの強化が実際に働くことを確認する。
- バランス検証は既存シミュレータと実戦を使い、編成相性で5レベル程度を覆せるという軸を崩さない。

軽量バランスシミュレータは現行のツリー投資・融合・守護などを再現しないため、前後比較の差分確認に限定する。強化適用はUnityの戦闘状態テストとブラウザの実行時検証で確認する。
