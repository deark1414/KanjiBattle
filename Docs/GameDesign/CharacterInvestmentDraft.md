# キャラ別ツリー育成

更新日: 2026-10-26
状態: 方針確定・基本実装済み。通常キャラへの投資を融合へ引き継ぎ、強化だけ無料で振り直す。数値は仮調整。

## ねらい

HP・攻撃・技能威力・発動率の全体強化施設を、キャラごとに複数回取得する強化ノードへ置き換える。戦果を仲間加入・増枠・機能解放・得意なキャラの強化へ配分する。全枝を最終的には開放可能にし、永久に取れない排他選択は作らない。

## 採用仕様・初期調整値

- 共通の軍師レベルを維持する。キャラごとの経験値稼ぎは増やさない。
- 通常26キャラの先に耐久・攻撃・専門強化の3ノードを設ける。個々のノードは1回取得、相互の取得順は自由。同じキャラへ計3回投資できる。
- 耐久は最大HP+20%、戦果4、第5局から。攻撃は+15%、戦果6、第10局から。技能は威力・発動率を各1.15倍、戦果8、第15局から。キャラ自体の加入章より早くは出さず、未加入キャラの強化ノードも隠す。
- 技能は既存の威力計算・確率判定に掛ける。確定役割スキルは100%のまま。移動距離・固定軽減率・コピー数などの固定ルールは変えない。数字・盾・壁・甲・丑・風・影は技能強化では効果が出ないため、同じ条件・費用の「守備 +4」に置き換える。
- 融合のHP・攻撃倍率は、同レベル素材の基礎HP・攻撃を重みにした強化倍率の加重平均。技能は素材倍率の平均、守備の加算分も素材の平均（四捨五入）。融合の基礎値に対して1回だけ適用し、素材数を掛け足さない。
- 敵はプレイヤー投資を参照しない。砂などの生成コピーは確定済みステータスを使い二重強化しない。影の変身は元の影の技能投資を使い、変身相手の個別投資を借用しない。
- 再戦・速度・稽古・融合などの機能施設は残し、ステータス／技能の全体倍率施設と区別する。
- 無料の振り直しは確認画面付き。キャラ強化に実際に支払った戦果だけを全額返す。加入・増枠・施設・共通レベル・経験値は保持する。返却時に台帳を消去し、二重返却しない。
- 旧4種の全体強化施設は購入不可・効果無効とし、既存の購入・強化費用は初回起動時に返却する。機能施設と編成枠は維持する。

## 保存と予算

- 保存先は `KanjiBattle.CharacterInvestment.Paid.v1`。ノードIDと支払額を保存する。全進捗削除では消すが、育成振り直しでは他の進行キーを触らない。
- キャラ強化は全78ノードで戦果468。加入・全増枠・残存施設の最終強化まで含む総額は1677。表40局の基礎戦果合計496の約3.38周分。戦果倍率施設を使わない場合でも各局5勝以内の総予算に収まる。
- 初回40勝だけで全購入できる設計ではなく、既存方針の少量周回込み。到達順と難易度を踏まえた実戦の所要時間は別途調整する。

## 検証と継続調整

- 表クリアまでの想定周回数・獲得戦果と、全解放の総費用を照合する。全解放が予算上可能なことを確認してから費用を決める。「初回クリアだけで全購入」か「既存の少量周回込み」かも区別する。
- 既存施設に支払った資源と得た効果を、移行時に失わせない。表示だけ先に消したり、全体倍率と個別倍率を両方適用したりしない。
- 同キャラ複数編成、融合、進化、変身、砂のコピーで効果の参照元を揃える。敵にプレイヤーの強化を適用しない。
- ダメージだけでなく回復・軽減・肩代わり・発動率など、能力ごとの強化が実際に働くことを確認する。
- バランス検証は既存シミュレータと実戦を使い、編成相性で5レベル程度を覆せるという軸を崩さない。

軽量バランスシミュレータは現行のツリー投資・融合・守護などを再現しないため、前後比較の差分確認に限定する。強化適用はUnityの戦闘状態テストとブラウザの実行時検証で確認する。
