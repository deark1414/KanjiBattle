# Facilities

`Stage Point` だけを使う現行施設一覧。施設は「解放」「レベルアップ」「ステージ到達によるレベル上限解放」の三つだけで進行する。

| 施設 | 効果 | 解放条件 | 最大レベル |
|---|---|---|---:|
| 勧誘所 | 勝利時の縁を `+1 / +2 / +3 / +5` へ強化する。 | 初期 | 3 |
| 兵舎 | 編成枠を増やす。 | Stage 3 | 5 |
| 訓練場 | 戦闘経験値を増やす。 | Stage 3 | 5 |
| 兵法書庫 | 戦闘速度の2倍、4倍を解放する。 | Stage 3 | 2 |
| 再戦所 | 勝利・敗北後に同じステージへ再挑戦できる。 | Stage 3 | 0 |
| 勝利の碑 | 勝利時の獲得SPを増やす。 | Stage 15 | 5 |

旧ゴールド、召喚、召喚確率、キャラクター重複、キャラクターレベル上限の施設は存在しない。
