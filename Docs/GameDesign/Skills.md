# スキル一覧（対象・効果）

## 共通

- 発動率は `CharacterData.skillChance` を参照  
- 威力は `CharacterData.skillPower` を参照  
- 対象選択は `BattleManager` + `TargetingService` のロジックに従う  

## ダメージ系

### Slash
- 対象: 8方向で1-2マス以内の敵
- 効果: 単体ダメージ

### Spear
- 対象: 8方向で1-2マス以内の敵
- 効果: 2マス貫通（1マス目・2マス目の敵にダメージ）

### Arrow
- 対象: 8方向直線上で最初に見つかった敵
- 効果: 単体ダメージ

### Gun
- 対象: 8方向直線上の敵がいる方向をランダム選択
- 効果: 選んだ直線上の敵全員にダメージ（威力低め）

### Stone
- 対象: 自身中心の半径2マス（5×5）範囲の敵からランダム
- 効果: 単体ダメージ

### Fireball
- 対象: 敵全体からランダム
- 効果: 防御無視の単体ダメージ

## 支援・状態異常

### StunBlow
- 対象: 隣接敵
- 効果: ダメージ + スタン（1ターン）

### WaterHeal
- 対象: 隣接味方
- 効果: 対象の最大HP割合回復

### Armor
- 対象: 自分
- 効果: 被ダメージ軽減（Lv×減少量）
- 調整: `skills.json` の `DamageReduction` 値

## 特殊行動

### WoodPush
- 対象: 隣接敵
- 効果: ダメージ + 押し出し

### Soil
- 対象: 自分
- 効果: 周囲に土罠を設置

### BirdRetreat
- 対象: 隣接敵
- 効果: ダメージ + ランダム退避

### HorseCharge
- 対象: 8方向2マス以内の敵
- 効果: 突進攻撃（移動＋ダメージ、詰まり時は先頭のみダメージ）

### TigerTwinClaw
- 対象: 隣接敵
- 効果: 連撃（同一対象に2回 + 隣接に追加攻撃）

## 反撃系（通常攻撃限定）

### Counter
- 対象: 被弾時の攻撃者
- 効果: 一定確率で反射

### AreaCounter
- 対象: 周囲8マスの敵
- 効果: 一定確率で範囲反射

## ボス系

### Dragon
- ブレス: 範囲攻撃（防御無視）
- 咆哮: ボス敵ドラゴンのみ有効
- 調整: `skills.json` の `dragonRoarChance` / `DragonBreath` 範囲

## パッシブ

### NumberPassive
- 対象: 味方の数字カテゴリ（1-9）
- 効果: 編成のユニーク数字数に応じて攻撃力バフ
- 「一」が複数いる場合は追加ボーナス
- 調整: `skills.json` の `numberPassive*` パラメータ
