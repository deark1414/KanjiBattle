# 丑の遠距離保護と防御強化

2026-10-26。ホルスタインの牛乳を「丈夫になる」防御強化に集約し、回復は追加しない。現行プレイアブルの丑（ID30）へ適用。進化後の牛を新規実装したものではない。

## 実装仕様

- 隣接8マスの味方が投射攻撃を受けると、通常の防御計算後の80%を肩代わり。その37.5%だけ丑が負担する。基礎では元ダメージ100→味方20・丑30。
- 引受分は切り上げ、引受量は切り捨て。残HPで支払える範囲までに制限し、HP不足のまま無料で吸収しない。残HP7なら最大18を引き受けて7を負担し、丑は倒れる。
- 育成は従来どおり肩代わり率を伸ばす。ただし完全無効化を避けるため最大90%。負担割合は固定なので、最大育成時は100→味方10・丑34。
- 発動時、自身と守った味方に防御+10%。各対象につき同じ戦闘ターン内1回、戦闘中最大+30%。別の丑から守られても同ターンには重複しない。
- 防御力そのものの割合強化であり、被ダメージを直接30%減らす効果ではない。賽子の防御補正と加算する。以降の攻撃に適用し、今回の被害を再計算しない。
- 次の戦闘で強化と発動記録をリセット。回復・復活はしない。引受ダメージにさらに防御を適用しない。
- 対象は弓・銃・散弾・投石・火球。自分への直撃、通常攻撃、槍、連鎖電撃、竜、罠、反射、転送には発動しない。
- 甲や複数の丑との多重肩代わりはなし。敵側も同じルール。壁の能力・ステータス・移動AIは変更しない。

## 検証方法

実際の戦闘処理を無音で動かす。共通Lv33、個別・カテゴリ強化なし、素材8枠。セーブは隔離する。

1. 射撃対策: 第25局の敵配置をLv33に揃え、剣・盾・甲・壁・丑の採用を各5シードで比較。灯の素材/融合も含め35戦。変更前の同条件35戦と照合。
2. 終盤の守備役: 第35・36・40局で盾・甲・壁・丑を各3シード、計36戦。前回の名簿比較と同じ編成・配置・シードを使う。
3. 戦闘ルール・データ検査、ブラウザでの肩代わり・防御累積・残HP上限・非対象攻撃・両陣営の回帰確認。

少数の固定編成での比較であり、全編成の勝率ではない。終盤は敵側の丑も強化されるため、味方丑だけの変更効果と断定しない。乱数は演出と共有されており、同シードでも行動ごとの同じ乱数を保証しない。

実行記録: `tmp/balance/ox-defense-projectile`、`tmp/balance/ox-defense-late`。

## バランス結果

変更後71戦を実行。比較元は前回の同条件データを使用し、変更のない剣・盾・甲・壁の結果も一致した。

|射撃編成への採用|勝利 変更前→後|平均終了ターン 前→後|軍勢の平均残HP率 前→後|
|---|---:|---:|---:|
|剣|4/5→4/5|9.4→9.4|28%→28%|
|盾|4/5→4/5|11.6→11.6|30%→30%|
|甲|4/5→4/5|11.6→11.6|25%→25%|
|壁|5/5→5/5|10.4→10.4|54%→54%|
|丑|4/5→4/5|10.0→10.0|23%→25%|

丑自身の平均肩代わり量は69.2→134.4、軽減・防止記録は60.6→123.4。後者には基礎防御による軽減も含む。灯は素材・融合とも5/5勝で変化なし。

終盤は盾・甲・壁・丑いずれも、変更前後とも第35局3/3、第36局2/3、第40局0/3。丑入りの平均軍勢残HP率は28.9%→30.0%、丑自身の平均肩代わり量は70.0→121.7。第40局は敵側の丑にも変更が適用される。

**判断:** 保護量は増えたが、この固定混成編成では勝敗逆転までは起きず、万能化は確認しなかった。射撃相手の残HPは壁が依然高い。一方、これは隣接を維持できる専用護衛編成の評価ではない。肩代わり可能な位置を保つ行動AI、守る対象を変えた布陣、複数の丑、最大育成の採用価値は次の検証課題。今回は合意した能力だけを実装し、壁の弱体化や動物の2マス移動変更は行わない。
