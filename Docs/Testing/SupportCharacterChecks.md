# 鈴・糸・影の確認

更新日: 2026-10-24

## 実装範囲

- 鈴: 隣接8マスの味方の成功スキルを25%で再発動。施設の発動率補正を適用。複数鈴は最大確率の1体だけ抽選。追加は1行動1回までで、追加発動からは再抽選しない。元の対象の生存・射程を再確認し、無効なら追加なし。変身・通常攻撃・反撃・常時能力は対象外。
- 糸: 射程2マス、攻撃80%相当のダメージと1マス引き寄せ。対象が射程内なら接近せず使用。味方への被害なし。移動先が埋まっている・水・盤外ならダメージだけ。移動先の罠は到着後に解決。
- 影: 隣接する基本キャラに1戦1回変身。最大HP・現在HP・残りスタン・自軍のレベルは維持し、対象の攻撃・防御・カテゴリ・スキルを写す。ボス・進化フラグ付き・負IDの融合は対象外。変身先の共有データは変更しない。
- 変身前の定義を保持し、敵の縁・所持キャラ・再戦素材を変身先へ置き換えない。
- 第16～20局を鈴・糸・影の章へ変更。遭遇・撃破・勝利を経て既存の縁システムから加入する。敵レベル・戦果・枠上限は今回変更しない。
- JSON・キャラアセット・両方のキャラDB・ステージアセットを同期。保存形式5への変更で旧開発セーブを初期化。

## 確認方法

- `BattleRuleRegression.RunFromCommandLine`: `SupportSkillRegression`も実行。支援の陣営・距離・死亡除外、確率端点、複数鈴での追加回数、変身制限、HP維持、共有定義不変、糸の射程・隣接引き寄せ失敗を確認。
- `GameDataValidator.ValidateFromCommandLine`: キャラDBの一致、JSONのID、ステージ参照を確認。
- `node scripts/e2e/run.js --only support-battle`: 実ブラウザの編成・配置・戦闘で引き寄せと変身を観測し、所持数不変・再戦時の原形復元を確認。
- `node scripts/e2e/run.js --only support-abilities`: テスト専用ビルド内で能力を直接発動し、鈴2体でも追加1回、糸のダメージと水・占有時の移動不発、変身時のHP維持を確認。確率はこの検証中だけ既存の確認用フラグで固定し、終了時に復元する。手動の新キャラ編成・通常版の確率は変更しない。
- `node scripts/e2e/run.js --only support-recruitment`: 通常融合用の初期編成から、未所持の3体の撃破登録・勝利累積・手動加入処理・再読込後の所持維持を確認。ここでの勝利累積は加入サービスへ直接渡すテストで、35試合を実戦したものではない。
- 3ケースまとめての再実行は`--only support-abilities,support-battle,support-recruitment`を指定する。
- 手動確認: `http://127.0.0.1:8796/?preset=support`。URLを開くたびにデバッグ側だけ初期化する。
