# 干支と丑の育成支援

更新日: 2026-10-24

## 実装範囲

- ID23・24・25を馬・鳥・虎から午・酉・寅へ改名。通常形を干支、進化形を動物名とする設計へ接続する。既存の素ステータス・突進／後退／双爪・動物2マス移動は維持。
- 丑をID30の基本動物として追加。Lv.1 HP140・攻撃20・防御10、毎レベル7・3・1の仮値。通常の近接攻撃・動物移動と、勝利経験値1.5倍を持つ。
- 第31～33局は午・酉・寅の間へ改名。第34局を丑の間、第35局にも丑を配置し、第7章を4系列にする。局数・敵レベル・枠上限・戦果は変更しない。
- 丑は遭遇・撃破・勝利による既存の縁を経て加入。加入登録も第34局に接続する。
- 旧字が描かれたアイコンは外し、午・酉・寅・丑は暫定の漢字表示。専用画像、進化の馬・鳥・虎・牛は未追加。

## 経験値の規則

- 出撃した元の編成から倍率を求める。撃破されても有効。戦闘中の影の変身によって倍率は変えない。
- 同種複数でも最大倍率1つだけを適用する。計算器は将来の牛2倍にも対応するが、牛そのものの進化・加入はまだ実装していない。
- 施設倍率と乗算し、最後に1回だけ切り上げ。既存の施設だけの計算結果が変わらないよう、従来と同じ浮動小数精度で掛け合わせる。
- 勝利時の軍師経験値のみ。敵側・所持のみ・敗北・引分・訓練・縁・戦果には適用しない。
- リザルトに経験値補正を追加表示。既存のレベル・経験値は新しい値だけを表示し、旧→新表示には戻さない。
- 保存形式5を維持。既存3系列のIDは変えず、この更新では追加の進行初期化をしない。

## テスト

- `BattleRewardRegression`: 最大倍率、重複禁止、施設との乗算、丸めの互換、途中切上げ禁止、上限オーバーフローを確認。戦闘ルール検証から実行。
- `animals-dead`: 開戦後にテスト操作で丑だけを撃破し、残りで実際に勝利。元編成の1.5倍適用、戦果不変、再戦での丑復元を確認。
- `animals-double`: 丑2体でも1.5倍。
- `animals-enemy`: 丑を所持していても編成せず、敵側の丑を倒した場合は通常経験値。
- `animals-defeat`: 丑を出撃させた敗北では経験値・戦果なし。
- `animals-recruitment`: 縁の撃破登録・勝利累積・加入・再読込後の保存。累積は加入サービスへ直接渡す検証で、必要回数の試合を実戦するものではない。
- `animals-mobile`: 縦長の実戦と、経験値補正を含むリザルトの文字収まり。
- 既存の18シナリオも実行し、旧キャラ・防御・融合・再戦・連戦への影響を確認する。

手動URL: `http://127.0.0.1:8796/?preset=animals`。丑・午・酉・寅・剣・水を準備する。開くたびデバッグ側の進行だけ初期化する。

加入までの必要勝数・高難度周回との時間効率・施設込みのバランス確定は、ロードマップの表全体調整で扱う。
