# 盾・甲・弓の確認

更新日: 2026-10-24

## 実装

- 盾: 反射ではなく、防御計算後に追加20%軽減する常時能力。正の被害の最低値は1。
- 甲: 第12局の旧通常鎧を置換。ID14・既存の遭遇／加入経路は維持。Lv.1 HP180・攻撃18・防御12、毎レベル8・2・1の仮値。進化形の鎧を基本キャラへ混在させない。
- 隣接8マスの味方の軽減後被害25%を、最大割合の守護者1体へ移す。同率時はインスタンス番号の小さい方。自身は守らない。死亡・HP0・敵・遠方の甲は対象外。
- 肩代わりの端数は切り捨て、移す量は守護者の現在HPまで。HP1で巨大な攻撃を25%吸収し続ける挙動を避ける仮案。守護者は肩代わりで撃破される。
- 通常攻撃・スキル・罠による直接被害を保護。反射・肩代わり由来の被害は転送しない。移した量に防御・自己軽減・反射を再適用しない。
- 弓: ID17と射撃能力を維持して矢から改名。第22局の表示名も更新。甲・弓の旧字アイコンを外し、専用画像が揃うまでは漢字で表示。
- 保存形式は5を維持。IDは変えず、追加の全セーブ初期化は行わない。

## 確認

- Unityの`BattleRuleRegression`に`BattleDamageRegression`を接続。軽減・分配・最低値・HP上限・守護者選択・自己／敵／死者除外を確認。
- `GameDataValidator`でJSONとDB・ステージ参照を検証。
- `defense-abilities`: 実際の被ダメージ処理で20%軽減後の25%分配、守護者1体のみ、再転送禁止、反射の転送禁止、守護者撃破、敵側の同ルールを検証。
- `defense-battle`: 通常の自動戦闘で肩代わりを観測し、勝敗後の再戦で原編成に復元することを確認。
- 手動: `http://127.0.0.1:8796/?preset=defense`。このURLはデバッグ側の進行を初期化する。

敵レベル・ステージ報酬は変更しない。第3章の難易度、専用アイコン、進化の鎧・亀、通常融合の追加は別の検証対象。
