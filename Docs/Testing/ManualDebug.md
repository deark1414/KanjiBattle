# 手動確認用URL

ローカル専用。`node scripts/e2e/manual-server.js`で起動する。事前にE2E専用版が必要。
作成されていない場合は`npm run qa:e2e:build`でビルド・検証する。

- `http://127.0.0.1:8796/`: 初回は融合確認用の進行を準備。以降はデバッグ用の進行を保持して編成へ戻る。
- `http://127.0.0.1:8796/?preset=standard`: 勝利しやすい融合確認用の状態で初期化する。
- `http://127.0.0.1:8796/?preset=defeat`: 敗北・再戦確認用の状態で初期化する。
- `http://127.0.0.1:8796/?preset=locked`: 第19局突破・融合解放前の状態で初期化する。
- `http://127.0.0.1:8796/?preset=support`: 鈴・糸・影・剣・槍・水の編成。敵は剣・糸・鈴、双方レベル20で新能力を確認する。

`preset`付きURLは開くたびに**デバッグ用の進行のみ初期化**する。
通常プレビューの8795番とは保存領域が別。通常版には操作口やこの画面を含めない。
127.0.0.1にだけ公開する。公開用ホスティングには配置しない。

上部で初期状態を切り替えて「初期化」できる。「編成へ」は進行を保って確認用素材を並べ直す。
「次戦を強敵に」は同じ確認用ステージで次に出る敵を強化し、連戦の敗北停止を確認する。
戦闘自体を勝利・敗北へ強制終了させる機能ではない。

現時点の素材は二・剣・二・剣・三・銃。双剣・散弾を確認できる。
2026-10-24から初期配置の上下左右隣接で融合を指定する。斜め・離隔は個別運用。
配置中の線と枠・人数予告を確認して開戦する。競合時だけ「組合せ」で選び、未確定では開戦できない。
戦闘中に接近しても融合しない。既定の出現元は前側、同じ段なら左側の素材。
鈴・糸・影以外の新名簿キャラは、まだすべて実装されたわけではない。
2026-10-24に保存形式を5へ更新。第4章の差し替えに合わせ、旧形式の開発中セーブは起動時に初期化する。
