# 散弾の自動切替と磁石・雨の追加検査

更新日: 2026-10-27。

## 散弾の仕様

- 攻撃時に自動選択。対象周辺3マスに生存敵3体なら各攻撃力80%の範囲攻撃。1～2体なら選んだ敵1体へ240%の集弾。3倍は散弾1体分の80%を基準とする。
- 射程3は維持。射程内に3体を巻き込める標的があれば、近い単体よりそちらを優先。同条件なら近い標的を選ぶ。既存の灯への標的優先は維持。
- 味方・死亡済み・HP0の駒は人数に含めない。集弾では隣の敵へダメージを与えない。
- 既存の壁の遠距離無効、甲・丑の肩代わり、灯・繭の保護は通常の投射攻撃として適用する。壁反射は追加しない。
- 集弾時の弾と着弾強調は標的1マスだけ。ログに集弾/散弾を記載。戦闘前のモード選択は不要。双剣の攻撃回数・倍率は変更しない。

## 追加検査の条件

実際の戦闘処理を無音で実行。共通Lv33、個別・カテゴリ強化なし、素材8枠、各3シード。

罠のない第1局を検査用の土台にして敵を差し替えた人工戦場。第1局の攻略難度ではなく、ステージデータは変更しない。敵もLv33、密集射撃/分散射撃/動物の速攻は8体、敵の磁石＋雨は素材8枠を6体へ融合する。

密集と分散は敵の種類・数が同一で配置だけを変える。素材個別と1体融合は共通6体の初期位置を保持。2体融合では残りの味方を4体へ変更し、素材8枠を維持する。2体融合と1体融合は他の駒を固定した比較ではない。

最大育成、長期の進行収支、全編成での勝率は未検証。同一シードでも演出と戦闘の乱数は共有される。

### 判断と課題

- 分散と速攻は、この編成では磁石・雨の十分な対策にならなかった。特に雨は全域から中心を選べ、分散でも対象を見つけられる。磁石は後衛を盤端へ押すことで衝突が継続しやすい。前回の「強めの監視対象」を維持する。
- 融合を2体にすれば常に速くなるわけではない。密集射撃では磁石1体の平均5.0ターンに対し2体5.7、速攻では4.0に対し4.7。味方の減少と役割変更の影響を含む。
- 敵の磁石＋雨は強い。今回の素材個別・散弾では勝てず、味方磁石2体なら3/3勝、雨2体なら2/3勝。これは単独で万能というより、強い能力同士が必要になる危険の兆候。表の敵ボスへこの組み合わせをそのまま追加するのは保留する。
- 次に触る場合は、磁石の盤端衝突の威力・連続命中、雨の全域指定・重複を個別に比較する。今回は追加検査までとし、磁石・雨の数値やステージを自動的に変更しない。

## 散弾の終盤確認

第35/36/40局を各3シードで18戦測定。素材個別6/9勝、完成形7/9勝、完成形の平均終了11.3ターン、時間切れ0。

旧測定の完成形4/9勝・平均12.6ターン・時間切れ1に比べて改善した。旧測定後に丑等の改修もあるので、差をすべて散弾変更だけの因果とは断定しない。素材個別の勝利数・平均ターン・味方残HP率は旧測定と同じだが、第40局の敵残HPは一致しない。

## 再実行

```sh
node scripts/balance/fusion-stress.js --output tmp/balance/scatter-support-stress
node scripts/balance/roster-comparison.js --scatter-probe --source tmp/balance/roster-screen --seeds 3 --output tmp/balance/scatter-auto-mode
```

出力先に編成計画、データスナップショット、初期の両軍レベル/能力/位置/素材、成績、集計を保存。8素材枠と実際の敵配置の一致を検証する。`--summary`は再戦せず集計だけを再実行する。

96戦の戦闘自体は正常終了したが、初回集計はUnity座標に含まれる計算済みの長さを実座標と比較して失敗した。x/yだけを照合するよう修正し、回帰テストを追加した上で保存済み全96戦を再検証した。
