## 共通処理

- 初期配置で上下左右に連結した素材だけを候補とする。賽子の3素材も、全員が互いに隣接する必要はなく、3体の連結が必要。
- 競合する素材は勝手に確定しない。進化や負のIDの生成物を通常素材として扱わない。
- 未発見の完成形は「？」、開戦で発見、素材数分の枠は消費したまま。再戦は元の6体等へ復元する。
- 素値は既存の調整案の役割別倍率を採用。標準3.5/1.5/1.2、守備4/1.2/1.4、支援3/1.2/1.1、増殖2.5/1.2/1、賽子4.5/1.5/1.2を、同レベル素材平均のHP/攻撃/防御へ適用する。最終バランスではない。
- 保存形式5と既存レシピIDを維持。追加の全初期化や素材の恒久消費はしない。

## 重要な細則

### 移動・反射・被弾変化

波は扇状3セルの敵を遠い側から処理する。移動先が占有・水・盤外なら移動だけ不発とし、衝突ダメージやスタンは加えない。磁石は最初に選んだ敵の移動が不可能でも別の敵へ選び直さない。移動した先の罠は既存の着地処理へ渡す。

山の返還値は軽減・肩代わり後の実HP損失で、オーバーキル分を含めない。致死時も返還できる。返還専用の発生元区分を使い、防御・軽減・肩代わり・再反射を適用しない。通常の反射区分の挙動は従来どおり維持する。

炭は初めて生き残った敵の直接被害で一度だけ変化する。罠・転送・反射で変化しない。要塞の反撃は直接被害に25%で発生し、実HP損失の25%を隣接敵へ返す。迫撃砲は第1・3・5…ターンに重複しない最大2体へ攻撃50%。

### 賽子・雨

賽子の目は1～6を等確率で抽選。攻撃強化はその陣営の行動終了まで、防御強化は敵の攻撃を受けられるよう次の自陣開始まで残す。同種の強化は加算しない。素材の数字連携は自動継承しない。

雨は行動ごとに最もHP割合の低い生存味方のセルと隣接8セルへ設置する。設置直後と次の2回の自陣開始時、各層で最大HP3%回復。同一・別の雨とも重複し、配置は追従しない。既存域は設置者がスタン・退場しても残り回数を処理するという仮設定。盤外部分は切り捨て、領域は青いマスで表示する。

### 砂・草

砂人形は本体の一時強化前の最大HP・素攻撃・防御の半分。HPは満タンで出し、本体の現在HPに依存させない。施設のHP補正を二重適用しない。同時3体、本体退場で全消滅、人形自身は生成しない。再度空きがあれば次ターンに補充する。

草は直接被弾後、生存してHP75%以下なら元個体を残して子を生成。現在HPと最大HPはそのまま複製し、全快や分配はしない。子の攻撃は親の70%、防御は同じ。系列全体で1戦3回まで、盤面に空きがなければ回数を消費しない。子は親が退場しても残る。致死では分裂しない。

どちらも空いた隣接8マスへ生成し、次の全体ターンから行動。編成枠・加入・融合素材・撃破候補を増やさない。本体退場で除去した人形は古い行動順の控えに残っていても再行動しない。生成直後で行動できない個体を追風の優先候補から外す。

### 繭・風鈴・灯の仮設定

- 繭は保護されていない味方のうちHP割合が低い1体へ付与。盤内射程制限なし、自分も候補。行動を使い、敵の直接攻撃1ダメージ段で消費。複数枚は積まず、未消費の間はその戦闘中保持。罠・肩代わり・反射には消費しない。漢字に文字を重ねず、金色の枠で保護中を示す。
- 風鈴は初期15%、自身以外の全味方のスキルが対象。鈴と重なる場合は最大確率の1体だけを判定し、追加は最大1回。追加発動から再誘発しない。変身や常時・周期能力は再発動対象外。雨は追加設置できるが、繭は同じ対象へ重ね置きできない。
- 灯は隣接味方への投射を70%で回避。対象分類は弓・銃・石・火球・散弾。槍・連鎖電撃・迫撃砲・竜の息・通常近接攻撃は除外。自分は守らないが、別の隣接する灯からの保護は許可。同じ被害で複数灯を重ねて判定しない。
- 灯は通常近接行動を行う。投射の標的候補に射程内の灯がいれば、その中の最寄りを優先。射程外の灯へ無理に追跡しない。回避・保護で失われなかったHPから反射・分裂・燃焼を発生させない。

これらの未指定細則は初期実装用の仮置きで、回避率・保護頻度・多灯編成・回復の重なりは実戦バランス確認で調整する。

## 自動・手動確認

`CompleteFusionRegression`で17レシピ、22素材の網羅、3素材の連結、各生成値、致死反射・燃焼・保護・防御の有効期間を確認する。Playwrightには追加12種それぞれの能力確認と実戦・再戦を用意し、既存32件と合わせて56件となる。

手動画面の選択欄から全17種を試せる。新12種は次の形式で直接開く。

`http://127.0.0.1:8796/?preset=fusion-wave`

末尾の値: `fusion-wave` / `fusion-magnet` / `fusion-mountain` / `fusion-coal` / `fusion-fortress` / `fusion-dice` / `fusion-rain` / `fusion-sand` / `fusion-grass` / `fusion-cocoon` / `fusion-windchime` / `fusion-lantern`。

各URLはデバッグ側だけ初期化し、素材を連結配置して準備する。通常版の進行へは触れない。能力確認テストはHP・位置・乱数を制御し、実戦テストは別の初期状態から通常の自動戦闘を行う。

## 残る工程

17/17は能力・操作・保存の接続数。後続の原画制作で17種のコマ・モチーフも接続した。専用スキル演出の仕上げ、融合を載せる図鑑画面、成績集計、全40局の融合／非融合比較、最終数値調整、進化・上位融合は未完了。簡易シミュレータはこれらの融合を再現しないため、その出力を融合の強さの根拠には使わない。
