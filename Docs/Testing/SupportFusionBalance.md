# 磁石・雨・賽子の能力改修

2026-10-26。通常融合の素材消費に見合う役割を作る。散弾の反射・モード切替は提案段階として扱い、この改修には含めない。

## 初期調整値

- 磁石: 自分のターン開始時、近接役を1マス引き寄せ、後衛役を1マス遠ざける。最大2体・同じ敵は1回。両役がいれば1体ずつ、片方だけならその役から2体。近い敵を優先。後衛は投射攻撃役と水・雨・鍛冶・鈴・風鈴・賽子・砂・灯。移動先が盤外・進入不可・他の駒なら攻撃力200%×技能効果の衝突ダメージ。空きマスを探し直さない。通常の防御・保護は有効。
- 雨: 行動時に3×3の固定範囲を設置。直後と次の自分側2ターン開始時の計3回。毎回、範囲内の味方を最大HP10%×技能効果回復し、敵へ設置時攻撃力50%×技能効果の持続ダメージ。層の重複可。設置者の死亡後も残る。持続ダメージから反撃・肩代わり・被弾分裂などを起動しない。通常防御は有効。
- 雨の範囲選択: 自動戦闘なので手動指定は追加せず、盤面全マスを候補に、その時点の実回復見込量＋敵へのダメージ見込量で中心を選ぶ。同点なら設置者に近いマス、さらに同点なら上・左。重ねること自体を禁止しない。
- 賽子: 毎ターン等確率の1～6。1・2は生存味方全体を全回復。3・4は全体防御2倍、5・6は全体攻撃2倍。第2ターン2.25倍、第3ターン2.5倍と0.25ずつ増し、第9ターン以降最大4倍。技能効果は加算ボーナス部分に掛け、最終上限は4倍。
- 賽子の攻防補正: 次の自分側ターン開始時に消す。敵の攻撃中も有効。複数の賽子の同種補正は最大値のみで重複しない。他の技能由来の補正は既存の加算ルールを維持。全回復は復活ではなく、満タン分の回復成績を水増ししない。

## 比較方法

実戦処理を無音で実行し、セーブは隔離。共通Lv33・強化なし・素材8枠、第35/36/40局、各3シード。各融合を素材個別と完成形で比較し、1回54戦。変更前後とも同じ条件を取り直す。少数の固定編成であり、全編成の確定勝率ではない。

出力: `tmp/balance/support-fusions-before`、`tmp/balance/support-fusions-after`。

```sh
node scripts/balance/roster-comparison.js --fusion-probe --source tmp/balance/roster-screen --seeds 3 --output tmp/balance/support-fusions-after
```

今回の新能力は段階的なバランス調整の初期値。最大育成・専用支援編成・複数採用・敵側での出現バランスは別途確認する。

## 測定結果

変更前54戦＋変更後54戦、計108戦。素材個別の勝利数は磁石8/9・賽子2/9・雨4/9で前後とも同じ。

|融合|完成形の勝利 前→後|平均終了ターン 前→後|時間切れ 前→後|
|---|---:|---:|---:|
|磁石|4/9→9/9|12.0→7.9|0→0|
|賽子|2/9→6/9|12.4→12.3|1→1|
|雨|2/9→9/9|13.3→6.8|1→0|

- 磁石: 衝突を含む本人の平均与ダメージ595.7→2128.7。位置操作が失敗しても無意味にならず、火力面の見返りが増えた。盤端の後衛を押すだけで衝突を起こしやすい点は強めの監視対象。
- 雨: 本人の平均与ダメージ0→2972.7、回復490.4→246.4。全域から中心を選べるため、敵の密集地点へ攻撃する運用が強い。戦闘短縮と敵陣への設置優先により回復の実績は減っており、「回復役としても十分」と断定しない。5×5への拡大は不要。
- 賽子: 平均回復499.3→2263.1。第35局3/3、第36局1/3、第40局2/3勝。全体強化が成立するが、出目と前衛の生存に左右され、時間切れも1件残る。

**判断:** 3種の融合する意味は改善した。ただし磁石・雨は最終局まで全勝しており、弱すぎる問題の解消をもって調整完了とはしない。次は位置の散った敵・高速接近・専用対策編成、複数採用と最大育成を確認する。敵の密集配置と全域攻撃の相性を分け、必要なら雨の射程・重複・威力、磁石の衝突威力を個別に調整する。今回はステージデータや散弾の仕様は変更しない。

## 動作確認

- Unityの戦闘ルール・データ検査とWebGLビルド成功。磁石の前後方向、賽子の倍率増加・上限、持続ダメージと直接被弾保護の区別を検査。
- Playwright 8件成功。3種の固有能力と実戦・再戦、山と草の既存能力を確認。両陣営、磁石の最大2体・地形/駒/盤端衝突、雨の自動中心・重複・3回終了・攻撃力の設置時固定・設置者退場後継続、賽子の全6面・全回復・攻防持続/消去/上限を含む。
- 結果: `tmp/e2e/support-fusions/index.html`。雨の実画面画像も確認。測定・操作基盤のNode 20件成功。
- 素材個別27戦は変更前後で勝敗・終了ターン・両軍残HPがすべて一致。

## 散弾の検討メモ（未実装）

壁反射は実装可能だが、反射方向・二重命中・射程・味方への命中の扱いが増える。集弾/散弾モードは戦闘前に選択する方式を提案する。現在の散弾は1体あたり攻撃力80%なので、「散弾1体分の3倍」を基準にするなら集弾は単体240%。攻撃力そのものの300%とは区別し、ボスへの瞬間火力を別途比較する。どちらのモードも壁への遠距離無効を迂回しない案。いずれも未採用・未実装。
