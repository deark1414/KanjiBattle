# 電・風・鉄の確認

更新日: 2026-10-24

## 実装

- 電（ID31）: 初撃は周囲3マス。命中した敵の隣接8マスから未命中の敵をランダムに選び、最大4体へ連鎖。威力は100%→75%→56.25%→42.1875%。各段で既存の防御・軽減を適用する。味方・同じ敵への再命中なし。途中で敵を倒しても、そのマスから次を探す。
- 風（ID32）: 自軍行動前に、移動+1なら攻撃圏へ入れる味方がいれば自分と味方1体へ追風。それ以外はランダムな敵1体へ向風。移動は最低1、同方向の補正は重複せず、追風と向風は相殺。通常の攻撃・移動行動は別に行う。スタン中は風を起こさない。
- 風の解除は対象陣営が次に行動し終えた時点。敵の風が味方行動後に付けた向風は、次の味方行動に反映されてから消える。場外・水・占有マスへの着地は従来どおり禁止。追風の動物は最大3マスで、着地演出・罠判定の待ち時間も延長する。
- 鉄（ID33）: 自分の行動開始時に形態を1つ選ぶ。HP半分以下なら盾（防御計算後さらに25%軽減）。それ以外は剣の扇状に敵2体以上なら剣、槍射程に敵がいれば槍、残りは剣で接近する。既存の剣の中央・側面倍率と槍の貫通・味方遮断を再利用。盾は通常近接攻撃を行い、剣・槍スキルを併用しない。形態は次の自分の行動まで維持する。
- 第36～38局に電・風・鉄、第39局にその混成を配置。第40局の竜は維持。敵数・レベル・報酬・罠数は変えず、全体バランスは後工程。
- 四～九はJSON・両DB・加入表・敵編成から除外。旧アセットと列挙値は参照保全のため残すが、プレイ可能な名簿には含めない。新キャラへのID流用はせず、保存形式5も維持する。
- 専用アイコン・完成版VFXは未作成。電・風は色付き着弾・表示、鉄は既存の武器演出で暫定確認する。

## 検証

- `ElementSkillRegression`: 形態の優先順、初撃射程、移動増減・最低移動、盾の軽減と肩代わり由来の軽減禁止、効果相殺、対象陣営の行動終了時だけの解除。
- `element-abilities`: 実際の能力呼出しで連鎖の減衰・4体上限・友軍除外・射程、剣の複数命中・槍の射程と味方遮断・盾の軽減と再変形、追風・敵の向風の解除時機を確認。戦闘開始前に検証用の配置・HP・攻撃を与える確定テスト。
- `element-battle` / `element-mobile`: 通常の自動戦闘で電と風の発動、リザルト到達、再戦で原編成・HP復元を確認。勝率の保証ではない。
- `element-recruitment`: 第8章の縁閾値と加入・保存、通常名簿26系列に四～九が含まれないことを確認。縁の蓄積は加入サービスへ直接渡し、100戦を実戦するものではない。
- 既存24シナリオも同じビルドで回帰確認する。

手動URL: `http://127.0.0.1:8796/?preset=elements`。電・風・鉄・午・剣・水を準備する。開くたびデバッグ側の進行だけ初期化する。

進化の雷・嵐・金、辰、残る通常融合、成績・図鑑は今回の対象外。ボスへの移動弱化は追加の免疫を設けず同じ最低移動1を適用するが、最終的な耐性・効き方は調整時に再検討する。
