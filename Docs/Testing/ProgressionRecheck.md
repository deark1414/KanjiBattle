# 支援融合改修後の進行再確認

更新日: 2026-10-27

## 採用した変更

- 第5局はLv4の一・二・三・二へ変更。一二三の連携と前後配置を最初の関門にする。
- 敵の融合は第10局の戦士から。以降の章末融合、プレイヤーの第20局突破＋融合施設の解放条件は維持する。
- 賽子自体の全回復・攻防2～4倍は維持する。通常融合17種中、敵として登場するのは6種、未登場は11種になる。
- 草・電・風・午・丑の性能値は今回は変更しない。

## 第5局の問題と比較

最新能力で実勝利報酬だけの通し攻略を行うと、第5局で7戦0勝となった。以前の通し攻略は賽子の能力変更前のため、そのまま現行の完走根拠には使えない。

追加比較は共通Lv5・3枠、前4局を各3勝した購入済み育成条件。剣・一・水、剣・盾・水、剣・剣・水、盾・盾・水を各5シードで確認。未加入キャラの無料使用はせず、出陣時の所持・枠・能力を検証した。実際の突破や勝利報酬まで再現する通し攻略とは区別する。

## 草・電と支援役の対策比較

## 表40局の通し攻略

新規セーブ・初期3枠、各局最大3勝/7試行、実際の勝利報酬のみで加入・増枠・技能強化を購入する。無料加入、レベル上書き、放置稽古、プレイヤースキルは使わない。混成/戦士融合は同じ購入方針で、第21局以降に剣＋盾を融合するかのみ変える。固定購入方針と適応配置であり、人の全加入分岐を網羅するものではない。

|方針|戦闘数|勝利|敗北|初戦勝利した局|平均ターン|時間切れ|
|---|---:|---:|---:|---:|---:|---:|
|混成・非融合|138|118|20|33/40|8.37|0|
|戦士融合|129|120|9|37/40|8.02|1|
|射撃中心・非融合|126|118|8|38/40|6.64|3|

両方とも全40局を突破し、最終的に共通Lv34・8枠。混成は第25局が7戦1勝で、全局3勝の達成ではない。戦士融合は全局で3勝を達成した。第25局は同じ到達Lv23から非融合1/7勝に対し戦士融合3/3勝であり、融合を活かす後半の関門として据え置く。第36局は両方3/6勝で難所として残る。

射撃中心も全40局を突破し、最終Lv34・8枠。第25局は3/3勝、第36局は3/3勝・平均4.33ターンだが、壁2体・丑・繭で守る最終局は1/7勝・平均18ターンで、全局3勝ではない。射撃の周回速度は強みとして残し、最終局では混成3/3勝・戦士融合3/3勝という別の選択肢があるため、今回は銃の追加弱体化や全局の一律強化は行わない。ただし3方針の最終局到達レベルや育成購入は完全同一ではなく、局所的な固定条件の確定勝率ではない。

出陣素材の所持・実レベル・枠・初期能力に加え、全記録の敵の種類・レベル・明示配置も計画と照合した。

## 再実行

すべて実際のUnity戦闘処理を使用し、セーブ・音声設定を隔離して無音で実行する。演出と戦闘は乱数を共有するため、同じシードが行動ごとの同一乱数を保証するわけではない。

```bash
node scripts/balance/fusion-stress.js --roles --seeds 3 --output tmp/balance/roles-current
node scripts/balance/opening-gate.js --output tmp/balance/opening-gate-current
node scripts/balance/opening-gate.js --numbers --output tmp/balance/opening-gate-numbers
node scripts/balance/campaign-balance.js --profiles mixed --seeds 1 --playthrough --farm-wins 3 --layout adaptive --require-clear --campaign-file Assets/Data/campaign-plan.json --output tmp/balance/current-campaign-adjusted
# --profiles fusion / ranged で別の攻略方針も独立した新規セーブから確認する。
```

生データ・比較計画・設定は各出力先のresults.json・plan.json・context.jsonに保存。混成はcurrent-campaign-adjusted、戦士融合はcurrent-campaign-fusion、射撃はcurrent-campaign-ranged。初回の第5局で止まった記録はcurrent-campaign-mixedに残す。最終3方針393戦、初回の停止確認19戦、対策比較96戦、序盤候補120戦で、今回新たに測定した戦闘は合計628戦。
