# 戦士・衛兵・鍛冶の確認

更新日: 2026-10-24

## 追加レシピ

| 素材 | 結果 | 能力 |
|---|---|---|
| 剣＋盾 | 戦士（-1003） | 剣の扇状攻撃、自己軽減20%、自分と最寄り味方1体の攻撃+20% |
| 槍＋盾 | 衛兵（-1004） | 槍の2マス貫通攻撃、自己軽減20%、自分と隣接8マスの味方を最大HP4%回復 |
| 火＋槌 | 鍛冶（-1005） | 武器系の味方を攻撃+25%。武器生成なし、通常行動は近接攻撃 |

剣の側面70%と槍の味方遮断・水越えは基本形と共通。盾の軽減を二重に掛けず、肩代わりで移された被害には再軽減しない。衛兵の回復は各対象自身の最大HPを基準に四捨五入・最低1・最大HPまで。戦闘不能者や敵は対象にしない。

## 強化と持続

- 戦士は第1・4・7…ターンに鼓舞を付与し、対象陣営の行動終了を2回迎えたら消す。1体だけでも自分は強化する。
- 鍛冶も第1・4・7…ターンに鍛造を付与。3回の行動終了で消え、次回に更新。攻撃・支援を使う通常行動は別に行う。
- スタンしている支援者はターン開始効果を出さない。付与済みの効果は支援者が退場しても残り時間まで有効。
- 同種の鼓舞同士・鍛造同士は加算せず、強度と残り時間を更新する。鼓舞20%と鍛造25%は別種なので加算45%。既存の数字による攻撃補正とも加算した後、施設補正を1回適用する。
- 相手陣営の行動終了では持続を減らさない。スタン中でも対象陣営のターン経過で消える。保存データには書かず、再戦で初期化する。
- 鍛造対象は表示名の部分一致にせず、基本ID10～13（剣・槍・槌・盾）とレシピの明示タグで指定。現在の武器系融合は双剣・散弾・戦士・衛兵。鍛冶自身、火・水・甲・鉄などへ自動拡張しない。未実装の刀・矛・斧・鎧・要塞等は追加時にタグを接続する。

## 素値

素材の同レベル平均から生成し、成長値は0にする。戦士・衛兵はHP4倍・攻撃1.2倍・防御1.4倍、鍛冶は3倍・1.2倍・1.1倍。既存の双剣・散弾の3.5倍・1.5倍・1.2倍は変更しない。施設のHP補正は生成後の初期化時だけに適用する。

これは仮値で、素材2体を別々に使う場合や鍛冶＋双剣の最終バランスを保証するものではない。キャラ・ステージのJSONと報酬は今回変更しない。簡易シミュレータは融合を再現しないため、融合の強さの検証には使わない。

## 確認方法

- `FusionSupportRegression`: レシピ・役割別素値・共有盾の競合・強化の重複と解除・数字補正との加算・鍛造対象・軽減と肩代わり・衛兵の射程と味方遮断。
- `soldiers-abilities`: 隣接から戦士と衛兵を実際に生成し、対象数・回復範囲・持続・実攻撃・軽減を確定検証。検証のためHP・位置を一時設定する。
- `forge-abilities`: 鍛冶と双剣を実際に生成し、対象制限・重複禁止・3ターン継続・第4ターンの再付与を確認。
- `soldiers-battle` / `forge-battle`: 自動戦闘で発動、リザルトと再戦、元6体・配置・全快・強化解除へ戻ることを確認。鍛冶側はスマホ縦画面。
- 既存28件も同一ビルドで回帰確認する。

手動URL:

- `http://127.0.0.1:8796/?preset=soldiers`: 戦士・衛兵の素材を隣接配置した6枠。
- `http://127.0.0.1:8796/?preset=forge`: 鍛冶・双剣の素材を隣接配置した6枠。

URLを開くとデバッグ側だけ初期化。未発見の結果名は「？」、開戦で発見、離すと非融合という操作は既存と共通。素材・所持数・通常版セーブを消費せず、追加の保存形式変更も行わない。専用アイコン・図鑑画面・完成版演出は未完成。
