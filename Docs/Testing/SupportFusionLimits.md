# 磁石と雨の制約調整

更新日: 2026-10-27。

## 採用する仕様

- 磁石の近接引き寄せ・後衛押し離し、最大2体は維持。移動不能時の衝突を攻撃力200%から100%へ変更。
- 同じ敵への磁石衝突は、複数の磁石がいても戦闘ターン内1回まで。移動そのものは制限しない。衝突が繭等で防がれてもその回の衝突枠は使用済みとする。翌ターンは再発動可。
- 雨の中心は設置者からチェビシェフ距離3以内。3×3の範囲なので雨の端は設置者から最大4マスに届く。盤外指定や直接APIによる射程外設置も不可。
- 雨は直後＋次の自分側2ターンの3回を維持。各回の味方最大HP10%回復・敵へ設置時攻撃力50%も維持。
- 同じ駒への雨の効果は、各陣営から戦闘ターン内2回まで。既存エリアの持続、追加設置、鈴/風鈴の再発動、複数の雨を合算する。自軍の雨による回復と敵軍の雨によるダメージは別枠。満タンへの空回復は枠を消費しない。
- 雨の自動配置は射程と残りの効果枠を考慮する。回復も攻撃もできる対象がいないときは技能を使わず、既存の行動規則で前進する。意味のない設置を繰り返して後方に留まらない。
- 雨の場所固定・設置時攻撃力の保存・設置者退場後の継続、持続ダメージで反撃等を起動しない仕様は維持。賽子・散弾・牛・ステージデータは変更しない。

## 比較条件

前回の[追加検査](ScatterAndFusionStress.md)と同じ96戦を再実行。共通Lv33、強化なし、素材8枠、各3シード。密集/分散/速攻/敵にも磁石＋雨の人工戦場を使用する。実ステージの初回到達難度ではない。

素材個別と1体融合は共通6体の初期位置を維持。2体融合は残り4体へ変更する同素材枠数の比較で、1体融合へ単純に追加した比較ではない。演出と戦闘の乱数は共有する。

試行A（96戦）は上の制約だけを導入。雨が届かなくても空のエリアを設置し続け、密集/分散の雨2体で各3戦すべて20ターンの時間切れになったため不採用。

試行B（96戦）はAと同じ制約に「有効な対象がいなければ前進」を追加し、採用候補とした。射程を広げて元の安全な全域攻撃へ戻すのではなく、配置と接近が必要な役割にする。

第35/36/40局を各3シード、素材個別と完成形で計54戦確認。共通Lv33・強化なし・素材8枠、前回と同じ配置を使う。

|---|---:|---:|---:|---:|

磁石・雨の完成形には時間切れなし。雨は射程と接近が必要になり、戦闘が長くなるなかで回復の実績も増えた。回復係数を増やしたわけではない。雨はこの固定編成では全勝のため、強めの監視対象からは外さない。

素材個別と賽子の計36戦は、比較元と勝敗・終了ターン・両軍残HPがすべて一致。試行A96戦・試行B96戦・終盤54戦の計246戦を新たに測定した。

### 判断・残る課題

- 融合の使い道を消さず、安全な高火力と同じ対象への集中重複を抑える案としてBを採用する。
- 複数採用がそのまま火力倍増にはならない。雨2体は異なる対象を覆う運用、磁石2体は対象が分かれる配置が必要。同位置・同標的への集中採用は効率を落とす。
- 敵の磁石＋雨はまだ厳しい。味方が融合すれば必ず勝てる条件でもなくなっており、人工戦場の勝敗を「公平になった」とは評価しない。表のボスへの同時採用は引き続き保留。今回、敵編成やレベルを上げてはいない。
- 最大育成、全加入分岐、表全体の通し攻略は未確認。草・電等の別キャラの評価完了を意味しない。
