# 通常キャラ・融合の比較調査

条件: 共通Lv33、個別・カテゴリ強化なし、素材8枠、取得費用を除外して出陣キャラを加入済みにする、第35/36/40局、各3シード。
敵レベル: 第35局 33、第36局 33、第40局 37。
進行収支・初回到達の再現ではなく、固定した混成軍勢への採用比較。全勝率の推定や全編成の順位表ではない。
融合は同じ素材枠数と共通の支援駒を使い、素材を個別運用する場合と比較する。共通駒の初期位置を保持する。完成形は役割に応じて空いた前列／後列へ置く。素材の隣接禁止による配置差は残る。
通常キャラは共通7体へ1体追加する比較。基準の剣を含め、役割・配置の相性を含む採用価値の一次調査であり、個体の絶対的な優劣とはしない。
残HP率には砂・草などが生成したHPも含むため、通常の耐久率や融合前後の倍率として解釈しない。平均ターンは敗北・時間切れを含む。

## 留意点

実際の戦闘・地形・移動・スキル処理を使用。セーブと音声設定は隔離し無音で実行する。演出と戦闘が乱数を共有するため、同じシードも行動ごとの同一乱数を保証しない。
与ダメージ・回復・軽減の元記録はresults.jsonのcontributionsを参照。軽減・防止には基礎防御も含む。鈴の再発動・鍛冶の強化による追加ダメージは攻撃者側へ計上され、移動補助・引き寄せの価値も本人の成績には直接表れない。強化後、別の支援構成、別の初期配置、レベル差での再確認が必要。
