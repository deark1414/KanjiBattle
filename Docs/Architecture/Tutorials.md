# 初回導入・オープニング・機能説明

更新日: 2026-10-25

## 狙い

「漢字の魅力を発見しよう」を入口に、「漢字を仲間にして、編成・配置で勝ち筋をつくる自動戦闘ゲーム」であることを最初の1戦で伝える。短い和風の導入と実際のコマ画像を使い、説明をまとめて読ませず、機能に触れる時に表示する。

## 初回の流れ

1. 未突破かつ初回導線未開始なら、実際の第1局の編成へ直接入る。一・剣・水の3体を配置済みとする。
2. オープニング、編成の初回説明を表示する。オープニングはスキップ可能。
3. 出陣すると布陣の説明を表示する。剣を前、水を後ろに置く見本と、下2段の配置・自動戦闘を説明する。操作の強制・配置の自動変更はしない。
4. 開戦からは通常の自動戦闘。敵・戦闘処理・勝敗をチュートリアル用の疑似処理へ置き換えない。
5. 第1局で初勝利したら、経験値と戦果の説明から城下へ進む。城下の説明後、実際に枝を選べる。第1局の戦果を4から6へ変更し、初期加入費用6を払えるようにした。毎勝利6の通常報酬であり、説明を開き直しても報酬は加算しない。

初回の画面誘導は開始時に`entry`として記録し、次回起動から通常の軍勢画面へ戻る。第1局を未クリアでも初回導線を強制し続けない。未読の機能説明は、その画面を再び開くと表示する。既存の進行があるプレイヤーを第1局へ戻さない。

## 表示する説明

| ID | 初回表示のタイミング |
|---|---|
| formation | 編成画面 |
| deployment | 手動の布陣画面。自動戦闘の説明もここへ統合 |
| victory | 初勝利の結果。第1局だけ「城下へ」、それ以外は結果へ戻る |
| castle | 城下ツリー |
| player-skill | プレイヤースキル設定を初めて開いた時 |
| fusion | 融合所開設後、初めて手動で布陣する時 |
| records | 戦闘成績を初めて開いた時 |
| codex | 図鑑を初めて開いた時 |
| defeat | 初めての敗北・引き分けの結果 |

融合の説明にも完成形を出さない。素材のコマと「？」だけを示す。スキルの説明を閉じても選択内容は変えない。

## 保存と設定

- 各説明は全面を覆うモーダル。背後の編成・タブ・開戦等をクリックできない。背景クリックによる不意の既読化はしない。
- 「わかった」等を押した時に既読を保存する。画面遷移で閉じた場合は既読にせず、無効になった説明の待ち行列も破棄する。
- `KanjiBattle.Tutorial.Seen.v1`へ安定したIDで既読を保存する。版数更新や再読込だけでは既読を消さない。
- オープニングは機能説明の一度制限と分け、設定の「起動時にオープニングを表示」で起動ごとの表示を切り替える。`KanjiBattle.Opening.Enabled`へ保存し、初期値は表示する。
- 設定からオープニングの再生と、機能説明の一覧・見直しが可能。見直しでは既読・所持・編成・勝敗を変更しない。
- 進行リセットは既読と初回導線をリセットする。音量と同様、オープニングの表示設定はプレイヤーの設定として維持する。
- 結果の説明中は自動連戦を一時保留し、閉じたら元の一時停止状態へ戻す。中断時にも解除する。

## 実装の担当

`TutorialProgress`が保存、`TutorialContent`が文章とコマ指定、`TutorialDirector`が初回導線・一度表示・待ち行列・文脈キャンセルを担当する。`FullScreenGuideView`が全面描画・コマの図・縦横レイアウト、`GuideSettingsLayout`が設定欄の可読性を担当する。新しい画像は生成せず、既存の和風背景・コマ画像を利用した。

E2E専用ビルドの通常プリセットは説明を抑止し、既存の能力・保存テストを同じ条件で継続できる。抑止は`KANJI_BATTLE_E2E`内だけで、通常公開版にデバッグ用のバイパスは含まない。専用の`?preset=tutorial`は初期3体・第1局から導入全体を確認するためのデバッグ用進行リセットである。

テスト条件・成功範囲は[チュートリアルの確認](../Testing/TutorialE2E.md)を参照。新規プレイヤーに意図が伝わるかどうかのユーザーテストを、操作の自動テストで保証するものではない。
