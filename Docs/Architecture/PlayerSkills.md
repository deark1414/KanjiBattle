# プレイヤースキル

更新日: 2026-10-25

## 実装範囲

布陣画面から種類と発動ターン（1〜20）を指定する。指定ターンの開始時、全キャラの行動前に1戦1回だけ自動発動する。「なし」も選択可能。初回の既定値は「なし」。旧保存の21〜50ターン指定は20ターンへ補正する。

| 名称 | 効果（調整用の仮値） | 解放 |
|---|---|---|
| 鼓舞 | 生存している味方全体の攻撃+30%、2ターン | 初期 |
| 堅守 | 味方全体の被ダメージ-30%、1ターン | 第5局突破 |
| 癒し | 生存している味方全体を最大HPの25%回復 | 第10局突破 |

数値・名称・解放局は最終バランスではない。使用コストなし。スキル確率上昇、AI変更、配置変更、施設による時間延長は未実装。

## 処理順と集計

- 開戦時は融合成立、初期罠、決着判定、第1ターンのスキルの順。初期罠で決着したら発動しない。
- 継続効果は発動ターンを1ターン目として数え、最終ターンの敵行動終了で解除する。その後の地形罠には継続しない。結果表示・戦闘中断時も解除する。
- 攻撃はキャラ固有補正の後にスキル倍率を乗算・丸め、次に施設倍率を適用する。味方の融合体・生成体も対象、敵には適用しない。
- 防御は通常防御・固有軽減の後、肩代わり配分の前に適用する。正のダメージは切捨て、最低1。肩代わり・反射の受け手には重ねて適用しない。
- 回復は発動時の実際の不足HPだけを回復し、戦闘不能者は復活しない。継続効果ではない。
- 回復と追加軽減はリザルトの「軍師・スキル名」へ記録。特定キャラの育成実績には加算しない。攻撃強化後の実ダメージは攻撃した個体の成績に含む。

## 保存と再戦

`PlayerSkillRules`に定義・検証・保存、`BattleState`に戦闘内の一回発動と残りターンを分離した。

- `KanjiBattle.PlayerSkill.Plan.v1`に種類IDとターンを保存。保存形式5の既存データは初期化しない。
- 設定画面の決定は布陣中の仮設定。開戦で確定保存する。設定画面や布陣を取り消した場合は保存しない。
- 再戦・自動連戦は確定済み設定を再利用し、発動済み・残りターンは毎戦初期化する。未発動分を次戦へ追加しない。
- 不正なID・ターンや未解放の保存内容は、勝手に別スキルへ置換せず、開戦前の選び直しを要求する。
- 全進捗リセットで設定も削除する。解放状態は最高突破局から判定する。

## 確認

`PlayerSkillRegression`は保存・解放条件・一回発動・継続・終了処理を確認する。ブラウザ側の`player-skill-*`は実クリックによる設定、取消、保存、再読込、再戦、自動連戦、初期罠決着、未解放・不正設定を確認する。実効果の検証は専用ビルド内で実キャラの攻撃・被ダメージ・回復・成績集計を通す。進行条件だけは固定プリセットを使い、通常プレイの数十局分の到達速度を保証するものではない。
