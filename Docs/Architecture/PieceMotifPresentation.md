# 駒のモチーフ表示

2026-10-05: 漢字駒を薄くし、中央へ大きなモチーフを重ねる表示へ変更。

- 軍勢一覧と縁の候補: 選択時に1.2秒だけモチーフを召喚し、消えて漢字駒へ戻る。未加入の候補は駒と同じ色調で表示。同じ駒を再度押すと演出を再生する。
- 編成候補と編成済みの枠: 選択時に1.2秒だけ表示して漢字駒へ戻る。別のキャラを選ぶと前の演出を消して切り替える。画面を開いた直後や一覧の再描画では召喚しない。
- 行軍の敵編成: 開示済みの駒に表示。未クリア局の開示条件は既存のまま。
- 加入時: 固有技能の演出と一緒にモチーフが立ち上がる。
- 戦闘開幕: 両軍の駒に1.2秒表示し、消えてから戦闘が始まる。

`PieceMotifPresentation` が全画面の配置と登場演出を管理する。2026-10-24の量産版では、透明な512px枠の中央432pxへ内容を収め、駒の118%の領域へ表示する。駒本体の描画だけを24%の不透明度にし、モチーフとHP・レベル表示は個別に保持する。登場演出が消えると駒の不透明度を戻す。モチーフ自身は入力を遮らない。

槍は35度傾けて全長を見せる。弓は弓本体と矢を描いた専用絵へ変更。剣・槍には細い明色の縁を加え、薄い背景でも見失わないようにする。素材そのものの形は保持する。

2026-10-06: 承認済みの銃 `Gun_matchlock_v2_draft.png` と石 `Stone_detailed_draft.png` をゲーム用テクスチャへ反映。銃口の角度を修正し、石は大きい表示向けに描き直した。両方とも `Assets/Art/Drafts/PieceMotifs/` に原本を保管。

`Assets/Resources/UI/PieceMotifs/catalog.json` が45組の使用素材と味方・敵のコマを記録する。通常26系列、通常融合17種、敵専用の竜、砂人形が対象。甲・弓・酉、新7系列と融合17種の新規モチーフを生成し、その他は既存素材を継承した。元の輪郭や色を改変せず、透過の内容領域を検出して固定枠に収める。

`scripts/art/build-character-art.js`で原画から実行用テクスチャと筆文字コマを生成し、`CharacterArtImporter.ImportProduction`で設定・参照を反映する。旧`PieceMotifImporter.ImportReviewed`も同じ処理へ委譲する。モチーフは512px、コマは256px、Point・RGBA32・圧縮なし・ミップマップなし。`CharacterArtCatalog`は融合体・砂人形にもコマを割り当て、草の分裂個体は草の絵を使う。データ再取込でも参照を復元する。技能VFX本体は差し替えない。

現行の比較ページは`Docs/Art/character-art-gallery.html`。`node scripts/art/serve-gallery.js`で45組のコマ・モチーフを確認できる。旧`Docs/presentation-art-preview.html`は旧26種のレビュー履歴。現行のゲーム用定義と一致するのは新しい一覧である。制作プロンプト・検証手順は[制作記録](../Art/CharacterArtProduction.md)を参照。
