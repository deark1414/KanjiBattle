# 行動AI・射線・移動の共通ルール

更新日: 2026-10-26

## 弓・銃の最低射程

- 弓と銃は最低射程2マス。隣接8マスの敵を対象に選べず、通常攻撃への代替も行わない。銃は遠方の敵を狙っても隣接敵には貫通ダメージを与えない。味方・敵の両方に適用する。
- 射撃可能な別の敵がいれば、その敵を射撃できる。射撃対象がなければ既存の射撃位置探索で距離を取り、移動に1行動を使う。同じ行動で移動後の射撃はしない。逃げ場がなければ待機する。
- 斜めも1マスとする。味方・水を越える射線は維持。散弾・投石・火球は今回は変更せず、散弾は接近にも対応する融合として残す。
- 対象選択・実行・銃の貫通・範囲表示・説明文を同じ最低射程へ統一する。`BattleActionRegression` とブラウザの `shooting-dead-zone` で退避・包囲・遠方射撃・隣接敵への貫通禁止を検査する。

## 今回の実装

- 剣・槍・矢・銃・投石・火球・水回復は、その役割を通常行動として確実に使う。追加効果を持つ他のスキルは従来の確率判定を維持する。
- 弓と銃は8方向の直線・最低射程2マス。味方・水を越える。銃は選んだ対象の方向を撃ち、味方には当てず2マス目以遠の敵を貫通する。
- 槍は8方向2マス、水を越えるが味方の先には届かない。対象選択と実際の貫通処理の両方で遮蔽を確認する。
- 投石・火球は周囲2マス。火球のランダムな全盤面対象を廃し、範囲プレビューと揃える。
- 対象は原則、射程内の最も近い生存敵。同距離はランダム。斜めを1マスとする距離を共通化。剣は命中数最大の方向を選ぶ。
- 水回復は自分と隣接味方から、HP割合が最も低い負傷者を選ぶ。全員満タンなら回復行動を消費せず通常攻撃・移動へ進む。
- 攻撃可能な射線・射程内にいる遠距離キャラは、接近のために移動しない。射線がなければ攻撃可能な位置までの移動を計画する。
- 移動は通常1歩、動物2歩。味方を途中で越えられても、味方・敵・水のマスには停止しない。

## 停止と決着（2026-10-26）

- 試行調整として上限20ターン。第20ターンの処理後も双方が生存していれば引き分け（勝利報酬なし）。水は味方・敵とも対象の最大HPの基礎30%を回復する。水の個別強化は各+10ポイント、自然カテゴリ強化は各+5ポイントで、全取得時60%（回復率の上限も60%）。敵には育成効果を適用しない。

- 停止はターン境界だけでなく各行動の待機中にも適用する。行動間隔・移動補間・移動後の罠ダメージ・鳥の退避は停止中に進めない。確定済みの同期的な攻撃・反撃・肩代わりを途中で巻き戻す操作ではない。一部の表示専用エフェクトは消え切る場合がある。
- 行動前後とターン末の罠処理後に生存者を判定し、全滅後は残りのコマを行動させない。攻撃中に同期実行される反撃・生成などは解決してから判定する。両軍全滅は引き分け。現状は予約された復活を待つ仕組みではない。
- Playwrightの`battle-pause-390`／`battle-pause-844`で実ボタンによる途中停止・HPと座標の不変・再開後の決着・共通バーと盤面の領域分離を確認する。決着テストの全滅状態のみデバッグ操作で作る。

## 所有先

- `BattleRangeService`: 射程・射線・斜め距離。選択・実行・移動先探索の共通基準。
- `BattleActionRules`: 確率に左右されない通常役割の分類。
- `TargetingService`: 生存・陣営・射程を満たす対象とHP割合の比較。
- `BattleMovementPlanner`: ターン単位で到達可能な停止位置を探索。味方通過と停止禁止を両立する。
- `SkillExecutor`: 実行直前にも対象と射線を検証。対象選択だけで不正攻撃を防いだことにはしない。
- `BattleManager`: 対象選択・スキル／通常攻撃・移動を接続する。射線や経路探索そのものはここへ重複実装しない。

## 検証と残り

`BattleActionRegression` を `BattleRuleRegression` へ接続。射線、友軍遮蔽、確定行動、回復対象、対角距離、射撃位置への移動、動物の友軍通過、停止禁止、水の迂回を検証する。

今回、新キャラ・融合・進化は追加していない。射撃の頻度と初期配置が変わるため、既存のスキル確率を前提にした難易度・施設効果は改めて調整が必要。全ステージの勝率・周回時間を検証済みとは扱わない。
