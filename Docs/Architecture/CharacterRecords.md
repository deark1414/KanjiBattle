# 戦闘成績と統合図鑑

更新日: 2026-10-25

## 対象

現行の通常名簿と通常融合17種を対象に、軍勢の「図鑑」とリザルトの「成績」を接続する。進化・試練・上位融合そのものは追加しない。未実装形態の仮スキルや解放済みデータは作らない。

## 成績の定義

- 与ダメージ・被ダメージは実際のHP減少。過剰ダメージは含めない。味方への攻撃は与ダメージへ含めない。
- 回復は実際のHP増加を発生元へ記録。満タン時と過剰回復は含めない。雨は設置者が退場しても設置者へ帰属。
- 軽減は防御と軽減効果で除いた攻撃量。残HP超過による切捨てとは分離する。繭の無効化は繭の付与者、灯の回避は範囲内の灯（複数なら個体番号順の1体）へ帰属。完全防御は入射攻撃量を記録する仮定義。
- 肩代わりは甲が引き受けた量として別項目へ記録。味方全体のHP損失を消す効果ではないため、軽減へ重ねて数えない。
- 反射・返還は返したキャラの与ダメージ、土の設置罠は設置者の与ダメージ。地形の自然罠には攻撃者を付けない。
- 変身は元のキャラへ、砂・草の生成個体は生成元の成績へ集約する。生成によるHPの増加は回復に含めない。
- リザルトは出撃個体ごと（融合は融合後の1行）、生成個体は生成元へ合算する。融合行には素材を併記。

## 累計

- 加入済みで出撃した素材へ、勝利時のみ保存する。戦闘中に死亡しても対象。敗北・引分は表示のみ。
- 融合の全項目を各素材コマへ均等配分。同種素材・非融合の同種個体は合算し、勝利数は種類ごとに1戦1勝。
- 2素材・3素材の端数は6分の1単位の整数で保持。表示は小数1桁に丸め、端数の失われる切捨て保存はしない。
- リザルト確定は一度だけ。再戦・連戦は新しい戦績帳を作る。成績画面を開くと一時停止し、閲覧中に次の戦闘へ進めない。閉じると閲覧前の停止状態へ戻す。
- 試練を累計から除外する受け口は戦績帳に用意するが、試練本体は別工程。

保存キーは `KanjiBattle.CharacterRecords.v1`。既存の形式5のセーブを消さず追加する。未計測の過去戦績は0開始。過去の所持と融合発見は既存記録から公開状態を補完する。進行リセットで遭遇・成績・融合発見を削除する。

## 図鑑

- 未遭遇は「？」だけ。遭遇後は漢字のみ、加入／自軍の初融合後にスキルの詳細と既知レシピを公開する。
- 敵での遭遇だけではレシピ発見を記録しない。未発見の素材やモチーフを図鑑に出さない。
- 通常と融合を切り替え、加入／発見の件数を表示する。通常キャラでは勝利分の累計も閲覧できる。敵専用キャラは「敵将」に分け、通常26系列の加入達成数へ混ぜない。
- 敵専用の竜は遭遇すれば漢字を表示するが、加入済みとはしない。後工程の辰の加入や進化解放を代用しない。
- 収集報酬は付けない。進化・超融合・究極融合の分類は、それぞれの実装時に同じ開示原則で追加する。

## 検証

`CharacterRecordRegression.RunFromCommandLine` は端数保存、重複素材、勝利の一回確定、敗北・試練の非保存、遭遇と発見の分離、破損保存・リセットを検査する。

`scripts/e2e/record-scenarios.js` は実ダメージ・実回復、リザルト、図鑑、保存再読込、融合配分、敗北をブラウザで確認する。テスト用の能力呼出しは確認専用版に限り、通常ビルドには含まない。

### 2026-10-25 確認結果

- 成績を含むUnityの戦闘ルール検証とデータ検証に成功。確認用WebGLビルドも成功。
- 既存の戦闘・操作34件が成功。甲の成績についても、実HP減少・軽減・肩代わりが重複しないことを実ダメージ処理で検査した。記録は `tmp/e2e/character-records-final/report.json`。
- 横長時の見出し余白を修正後、追加6件を再実行し6/6成功。PC・スマホ縦横、開いた状態での回転、保存再読込、融合配分、敗北、閲覧中の連戦保留と閉じた後の再開を確認。記録は `tmp/e2e/character-records-window-final/report.json`。
- テスト基盤の9件も成功。画面写真と操作記録は各結果フォルダへ保存する。全ステージのバランス保証や外部公開の完了を意味しない。

手動確認: `http://127.0.0.1:8796/?preset=animals`。軍勢の「図鑑」、戦闘リザルトの「成績」から開く。確認用の保存は通常プレイから分離している。現在は通常・通常融合・敵専用の竜が図鑑対象で、進化・上位融合は後工程。
